- 새로 들어가는 것: `실행물/우편번호_자동검색기_v1.10_출품본.html`(SHA-256 `6447728b04811599a47cd2b52df3d137e3b7fb65cd374967a5914136d9c5f5e4`).
- **지울 것**: 저장소의 옛 `실행물/우편번호_자동검색기_v1.4_출품본.html`(v1.9를 이미 올렸으면 그것도)(Web IDE 파일 목록에서 오른쪽 단추 → Delete). 두 판이 함께 있으면 심사위원이 옛 판을 열 수 있다.
- 그대로 둘 것: `모의데이터/`(10.7. 올린 6종). 묶음에 넣지 않았다.
- 커밋 메시지: `v1.10 출품본·소스(사진 읽기·스티커·태블릿 인쇄·모의 심사·어르신 모의 사용 반영)`.

## 돌다리(handover-doldari)
- 처음 올리는 본 묶음: `README.md`, `.gitattributes`, `.gitignore`, `실행물/doldari_v3.7.1_portable_win64.zip`(SHA-256 `cbb6b9571634275780f971a9b02d06e8fd46afe0f1b90d3018a006c7d4e79a4f`)·`읽어보기.txt`, `모의데이터/`(업무폴더 zip·정답표·README), `소스/`.
- 커밋 메시지: `v3.7.1 휴대용 실행물·모의데이터·소스 등록`. v3.6 묶음을 이미 올렸으면 `실행물/doldari_v3.6_portable_win64.zip`은 지운다.
- 23MB 압축이 Web IDE에서 실패하면 그 파일만 빼고 커밋한 뒤 파일 목록 화면 「+ ▼ → 파일 업로드」로 따로 올린다(매뉴얼 10절).

## 올린 뒤 시험(가능하면 파이썬 없는 다른 PC)
1. 물어물어: 내려받은 HTML 열기 → 「예시로 해 보기」 → 우편번호 검색 → 양식1 내려받기(유사 행 비고에 「확인 필요」) → 「어르신 직접 입력」 한 바퀴(없는 번지 「9999」를 눌러 「찾지 못했어요」가 나오는지) → 「직원」 2초 → 「이 어르신 입력을 접수 화면으로 넘기기」.
2. 태블릿(있으면): 같은 HTML을 크롬으로 열어 세로 화면에서 첫 「알겠습니다」가 눌리는지, 머리 단추가 화면 안에 들어오는지.
3. 돌다리: 휴대용 zip 압축 풀기 → `돌다리_실행.bat` → 모의 업무폴더 zip을 풀어 그 폴더 읽기 → 초안 → 1-다 「원문 ▸」·넣기 → 내려받기 → 워드로 docx 열기(서식 끝 서명란까지).
4. 어르신 화면(v1.10): 「수성동 현대아파트」를 적으면 정읍 건물이 먼저 나오는지, 「정읍시 수성동」 → 「몰라요」면 숫자 대신 「우편번호는 창구에서 정해 드려요」가 나오는지, 아무것도 적지 않고 「직원 도움 받기」 → 「창구에서 할게요」면 접수 번호가 나오는지.
5. 돌다리(v3.7.1): 내려받은 docx의 1-나 「인수 직후 할 일」, 1-다 「인수 확인」 ☐, 4절 「인수자 질문·전임자 답」이 보이는지.
6. 막힌 단계·화면 문구·사진만 보내 주면 고친다. 수치는 직접 돌린 값만.

## 아직 사람이 확인해야 하는 것
- 휴대용 묶음이 실제 윈도에서 실행되는지(리눅스에서는 앱 구성만 확인). 「Windows의 PC 보호」 경고 문구.
- Web IDE의 파일 크기 한도(23MB zip).
- 엑셀에서 연 결과(LibreOffice로 대신 확인함).

## 돌다리 올림이 막힌 뒤(10.18.~19.) 정리

10.18. 저녁 Web IDE 커밋이 모두 「Prevented by server hooks」(이유 문구 없음). 웹 화면의 「파일 업로드」로 하나씩 올려 보니 `requirements.txt`만 「파일 업로드에 실패」 → `부품목록.txt`로 이름을 바꿈. 그래도 전체는 막혀 **다른 파일이 더 걸림**.

10.19. 로컬에 서버 훅 흉내(`바통/돌다리/도구/gitlab_hook_sim.py`)를 만들어 같은 묶음을 밀어 넣고, 실제 서버가 통과시킨 물어물어 묶음으로 규칙을 보정했다(비밀 값·전화·카드 번호 꼴은 물어물어에도 있는데 통과했으니 규칙이 아님). 남는 후보는 4개 파일이다.

| 후보 파일 | 걸릴 만한 규칙 | 대비(막히면) |
|---|---|---|
| `소스/돌다리_실행.bat`, `소스/실측.bat` | 실행 파일 확장자 | `.bat.txt`로 올리고 README에 「받은 뒤 .txt를 지우기」. 휴대용 zip 안의 bat은 그대로 |
| `실행물/doldari_v3.7.1_portable_win64.zip` | 압축 안 실행 파일(python.exe·dll·pyd 44개) | ① `.zip.txt`로 올리고 읽어보기에 이름 되돌리기 안내 ② 그래도 막히면 「패키지 및 레지스트리 → 패키지 레지스트리」(generic 패키지, curl로 올림. git 훅을 타지 않음) |
| `모의데이터/가온우체국_모의업무폴더.zip` | 압축 안 압축(07_기타의 제출자료 zip) | zip 대신 **풀린 폴더째** 올리고(43개), README에 「폴더 화면 → ⋮ → 디렉터리 다운로드」 안내. 정답표 항목(압축 안 파일)은 그대로 |

### 10.19. 할 순서(웹 화면 「+ ▼ → 파일 업로드」, 막히면 빨간 문구가 나옴)
1. `소스` 폴더에 `돌다리_실행.bat` 올려 보기 → 막히면 bat 대비.
2. `모의데이터` 폴더(없으면 새 디렉터리)에 `가온우체국_모의업무폴더.zip` 올려 보기 → 막히면 폴더째 대비.
3. `실행물` 폴더에 `doldari_v3.7.1_portable_win64.zip`(15MB) 올려 보기 → 막히면 `.zip.txt` 대비, 그것도 막히면 패키지 레지스트리.
4. 셋 다 통과하면 후보가 틀린 것이니 그 자리에서 멈추고 알릴 것. 하나라도 막히면 그 대비를 적용한 묶음(`GitLab올림_돌다리_v3.7.1_대비.zip`)으로 Web IDE에서 한 번에 올린다(시험하며 `소스` 바로 아래 들어간 `app.js`·`index.html`·`점검결과_v1.1.md`·`.gitkeep`은 지운다).
5. 올린 뒤: README 머리 v3.7.1, 휴대용 zip 내려받아 SHA-256 `cbb6b9571634275780f971a9b02d06e8fd46afe0f1b90d3018a006c7d4e79a4f`(`.txt`를 지운 뒤 잰다), 깨끗한 윈도 PC에서 `돌다리_실행.bat` 실행.

패키지 레지스트리로 올리는 법(3-②): 「설정 → 액세스 토큰」에서 `write_package_registry` 권한 토큰을 만든 뒤 PC 명령 프롬프트에서
`curl --header "PRIVATE-TOKEN: <토큰>" --upload-file doldari_v3.7.1_portable_win64.zip "https://gitlab.aigov.go.kr/api/v4/projects/1305/packages/generic/doldari/3.7.1/doldari_v3.7.1_portable_win64.zip"`
→ 저장소 왼쪽 「배포 → 패키지 레지스트리」에 보인다. README 「접속 주소」에 그 링크를 적는다. 토큰은 올린 뒤 바로 지운다(저장소·문서에 적지 않음).
