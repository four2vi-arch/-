- **지울 것**: 저장소의 옛 `실행물/우편번호_자동검색기_v1.4_출품본.html`(Web IDE 파일 목록에서 오른쪽 단추 → Delete). 두 판이 함께 있으면 심사위원이 옛 판을 열 수 있다.
- 그대로 둘 것: `모의데이터/`(10.7. 올린 6종). 묶음에 넣지 않았다.

## 돌다리(handover-doldari)
- 처음 올리는 본 묶음: `README.md`, `.gitattributes`, `.gitignore`, `실행물/doldari_v3.6_portable_win64.zip`(SHA-256 `72956a7c07520f3242185101fa50c19c0e550f1fec3f612eaeaeba50f239f28d`)·`읽어보기.txt`, `모의데이터/`(업무폴더 zip·정답표·README), `소스/`.

- 23MB 압축이 Web IDE에서 실패하면 그 파일만 빼고 커밋한 뒤 파일 목록 화면 「+ ▼ → 파일 업로드」로 따로 올린다(매뉴얼 10절).

## 올린 뒤 시험(가능하면 파이썬 없는 다른 PC)
1. 물어물어: 내려받은 HTML 열기 → 「예시로 해 보기」 → 우편번호 검색 → 양식1 내려받기(유사 행 비고에 「확인 필요」) → 「어르신 직접 입력」 한 바퀴(없는 번지 「9999」를 눌러 「찾지 못했어요」가 나오는지) → 「직원」 2초 → 「이 어르신 입력을 접수 화면으로 넘기기」.
2. 태블릿(있으면): 같은 HTML을 크롬으로 열어 세로 화면에서 첫 「알겠습니다」가 눌리는지, 머리 단추가 화면 안에 들어오는지.
3. 돌다리: 휴대용 zip 압축 풀기 → `돌다리_실행.bat` → 모의 업무폴더 zip을 풀어 그 폴더 읽기 → 초안 → 1-다 「원문 ▸」·넣기 → 내려받기 → 워드로 docx 열기(서식 끝 서명란까지).
4. 막힌 단계·화면 문구·사진만 보내 주면 고친다. 수치는 직접 돌린 값만.

## 아직 사람이 확인해야 하는 것

- Web IDE의 파일 크기 한도(23MB zip).
- 엑셀에서 연 결과(LibreOffice로 대신 확인함).
