## 2. 개요 및 주요 기능(핵심 요약)

### 10.12. 사전 송부본(공백 제외 약 790자)

활용성: 인사이동 때 전임자 PC에 한글(.hwp·.hwpx)·PDF·엑셀·워드·메일(.eml)·메모(.txt)로 흩어진 자료를 폴더째 넣는다. 규칙이 문서번호·시행일자·수발신·기한·반복 표현·업무 연락처 후보를 뽑아 인수인계 뼈대를 만들고, 생성형 AI가 「월별 할 일·협의할 사람·진행 중 현안」 초안을 항목마다 파일·쪽(시트)·발췌 출처와 함께 쓴다. 전임자가 화면에서 확인·수정·삭제·추가해 「확인됨」으로 잠근 항목만 후임자용 인수인계서(HTML·DOCX)로 내보내며, 공식 문서(문서번호 있음)와 개인 메모를 구분하고 불확실한 항목을 표시한다. 인사이동이 있는 모든 기관이 같은 구조로 쓰고, 기관별 업무분류와 추출 규칙은 CSV 2개로 설정한다(견본 2종 동봉). 출품·시연은 가상 기관의 합성 모의 업무폴더만 쓰며 실제 문서·개인정보는 넣지 않는다.
완성도: 원본 폴더는 읽기만 하고 결과는 별도 폴더에 만들며, 처리 전후 원본 SHA-256 대조표를 결과에 붙인다. 발췌가 원문에 없는 항목은 「불확실」로 내리고 근거 없는 항목은 만들지 않으며, 읽지 못한 파일은 사유와 함께 목록으로 남긴다. 파이썬이 없는 PC에서도 휴대용 묶음을 풀어 실행 파일 하나로 안정적으로 구동한다. 가상 기관 1년치 모의 업무폴더와 정답표로 자동 채점한 출처 일치율·지어낸 항목 비율·처리 시간·기대효과(수기 작성 대비 시간)는 11.9. 제출본에 수록한다.
확산 용이성: 특정 모델에 종속되지 않도록 OpenAI 호환 API 주소·모델 이름(내부망 모델은 키 없이)만 바꿔 교체하고, 공통기반 지원 모델 2종(엑사원 3.5 7.8B·젬마 3 4B) 구동 결과를 구동안내서에 수록한다. 모델이 없으면 규칙만으로 뼈대를 만든다. 수집·추출·규칙·모델 어댑터·검토·내보내기를 모듈로 나누고 중간 결과를 JSON으로 저장해 타 기관 이식과 정식활용(정보화사업) 이관 때 모듈 단위로 바꾼다. 문서시스템 API 연계를 가정한 수집기 인터페이스를 두고, 허용 목록 밖 외부 주소는 차단한다.
