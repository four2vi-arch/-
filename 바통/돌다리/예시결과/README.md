## 만든 조건과 결과 수치

- 인계 일자 **2026-03-02**로 고정(모의 폴더의 주된 기간 2025.3.~2026.2. 바로 뒤 첫 평일), 인계자 「김전임(가상)」, 인수자 「이신규(가상)」, 규칙만, 전임자 검토 전.
- 읽은 파일 41 · 못 읽은 문서 2 · 읽지 않는 형식 1 · 원본 변경 0
- 문서 항목 41. 「인수 직후 할 일」 4건, 1-다 현안 9행, 1-라 미결 3행, 반복 업무 제안 14건. 아직 고르지 않은 제안은 모두 [확인 전]으로 실렸고(24건), 문서 끝에 「전임자가 하나씩 확인한 항목 0/24건」이 적힙니다.
- 기한의 「(지남)」은 인계 일자 기준입니다. 인계 일자를 고정했으므로 언제 다시 만들어도 같은 기한·「(지남)」 표시가 나옵니다.

못 읽은 2개(손상된 한글 파일·암호 걸린 PDF)와 읽지 않는 형식 1개(스캔 그림)는 일부러 넣은 것이며, 인수인계서 「붙임 2. 확인하지 못한 자료」에 사유와 함께 남습니다.

## 다시 만들기

소스 zip을 푼 폴더에서 `python 도구/make_example_outputs.py <모의 업무 폴더> <출력 폴더>`를 실행합니다. 화면에서 직접 하려면 1-가 「일자」에 2026-03-02를 적고 초안을 만든 뒤 내려받습니다.

다시 만들면 두 곳이 다를 수 있습니다. 문서 끝 「작성 기준」은 만든 시각입니다. 날짜가 없는 메모 2개(`06_메모/할일.md`, `메모_한결물류.txt`)는 파일 수정일을 「(수정일)」로 적으므로, 압축을 푸는 프로그램이 수정일을 지키지 않으면 그날 날짜로 나옵니다.
