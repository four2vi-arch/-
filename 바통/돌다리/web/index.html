1. 업무 폴더

전임자의 업무 폴더를 지정하고 「읽기」를 누릅니다. 원본은 읽기만 하고 바꾸지 않습니다(처리 전후 지문 대조).

폴더 고르기
읽는 형식: 한글(.hwp 5.0·.hwpx, 옛 2.x·3.x는 어림), 워드(.docx), 파워포인트(.pptx), PDF(글자 있는 것), 엑셀(.xlsx·.xlsm·.csv), ODT, 메일(.eml), 메모(.txt·.md), 웹(.html), 압축(.zip). 그림·영상·프로그램·글꼴·임시 파일은 읽지 않고, 한셀(.cell)·암호 문서·스캔 PDF는 「못 읽음」으로 따로 적힙니다.

2. 설정·계획

모델 없이 규칙만으로도 몇 분이면 끝납니다. 모델을 고르면 문장 파일을 더 읽어 항목을 보탭니다.

분야 키워드 한 줄에 「분야: 키워드, 키워드」. 항목의 글·발췌·파일 이름에 키워드가 많이 든 분야로 분류합니다. 고치면 바로 다시 분류됩니다.

3. 초안 만들기

짧은 파일부터 모델에 보냅니다. 「여기까지만」을 누르면 그때까지의 결과와 전체 파일의 규칙 항목으로 검토 화면이 열립니다. 모델 응답은 호출마다 저장되어 중간에 꺼져도 다음에 이어서 갑니다.

아직 시작하지 않았습니다. 「2. 설정·계획」에서 「초안 만들기」를 누르세요.

4. 검토

틀리거나 필요 없는 항목은 체크를 풀면 인수인계서에서 빠집니다. 글은 바로 고칠 수 있고, 메모 칸에 후임자에게 남길 말을 적습니다.

분야
주기
직접 적기 문서에 없거나 모델이 못 잡은 것. 출처는 「전임자가 직접 적음」으로 남습니다.
불확실(제외): 발췌가 원문에서 확인되지 않아 뺀 모델 항목
처리 중 오류

주기 업무 확인

매주·매월·분기·반기·매년 되풀이되는 일을 묶어 보여 줍니다. 후임자가 계속 해야 하는 일은 남기고, 끝난 일은 묶음째 뺄 수 있습니다. 체크 상태는 검토 화면과 같습니다.

분야별 보기

분야 키워드로 나눈 항목 수입니다. 분야를 누르면 검토 화면에서 그 분야만 보입니다. 키워드는 「2. 설정·계획」에서 고칩니다.

읽은 파일

형식별 수와 글자 수, 못 읽은 파일의 이유입니다.

5. 내보내기

파일은 작업 폴더에 저장됩니다. .docx는 워드·한글에서 열어 꾸미고, 원본지문.csv는 처리 전후 원본이 바뀌지 않았다는 증빙입니다. 인수인계서에는 개인정보(전화번호 등)가 들어 있으니 업무 목적 외 사용·보관을 금합니다.
