# 돌다리 v1.0 · 추출층·모의 업무폴더·관문 ② 실측 도구(2026-10-09)

세션2 지정과제① 업무바통(인수인계) 출품작 「돌다리」의 첫 조각이다. 10.20. 관문을 앞당겨 재기 위해 추출기·모의 업무폴더·정답표·실측 스크립트를 먼저 만들었다. 검토 화면·내보내기 등 나머지는 실측 결과를 본 뒤 만든다.

| 파일 | 하는 일 |
|---|---|
| `extract.py` | 자체 추출기. .hwp(한글 5.0, olefile+zlib로 직접 읽음)·.hwpx·.pdf·.xlsx·.docx·.eml·.txt/.md/.csv·.zip(안의 파일 재처리). 원본은 읽기만 하고 처리 전후 SHA-256을 대조표로 남긴다. 못 읽는 파일은 사유와 함께 목록에 남긴다 |
| `make_mock.py` | 가상 기관 「한빛군청 행정지원과 서무담당」 1년치 모의 업무폴더 36개 파일과 정답표를 만든다. 기관·사람·전화·업체·문서번호 모두 가상 |
| `measure.py` | 로컬 모델(OpenAI 호환 주소)로 파일마다 출처 달린 항목을 뽑고 정답표로 채점한다. 결과.md(관문 판정표)·결과.json·인수인계_초안.md를 쓴다 |

## 실측 순서(미니PC, 10.10.~10.11.)

1. Ollama를 설치한다(ollama.com → Download for Windows). 설치 뒤 명령 프롬프트에서 모델 2종을 받는다(합쳐 약 8GB, 인터넷 필요).
   ```
   ollama pull exaone3.5:7.8b
   ollama pull gemma3:4b
   ```
2. 이 폴더(`돌다리_실측`)를 바탕화면에 풀어 둔다. 안에 `가상기관_모의업무폴더`와 `정답표.xlsx`가 있다.
3. 폴더에서 주소창에 `cmd`를 치고 아래를 차례로 실행한다. 첫 줄은 패키지 설치(한 번만), 둘째·셋째 줄이 모델별 실측이다. 각 실측은 파일 34개에 모델을 34번 부르므로 CPU에서 10~30분 걸릴 수 있다. 끝나면 결과표가 화면에 찍히고 `결과_모델이름\결과.md`에 남는다.
   ```
   python -m pip install -r requirements.txt
   python measure.py 가상기관_모의업무폴더 정답표.xlsx 결과2_exaone --model exaone3.5:7.8b --label "Ryzen 7 6800H 8코어 28GB CPU"
   python measure.py 가상기관_모의업무폴더 정답표.xlsx 결과2_gemma --model gemma3:4b --label "Ryzen 7 6800H 8코어 28GB CPU"
   ```
4. `결과2_exaone\결과.md`, `결과2_gemma\결과.md` 두 파일과, 각 폴더의 `인수인계_초안.md`를 보내 주면 관문 ②를 판정한다.

모델 없이 배관만 확인하려면 `python measure.py 가상기관_모의업무폴더 정답표.xlsx 결과_점검 --model fake`(정답을 그대로 돌려주는 가짜 모델, 100%가 나와야 정상).

## 1차 실측(10.9. 밤, 미니PC Ryzen 7 6800H·28GB·CPU, 1차판 measure.py)

| | 엑사원 3.5 7.8B | 젬마 3 4B |
|---|---|---|
| 처리 시간(34개 파일, 호출 34회) | 754.8초(평균 22.2초) | 686.5초(평균 20.2초) |
| 출처까지 맞은 정답 항목(경로 표기 고쳐 재채점) | 13/36 = 36.1% | 16/36 = 44.4% |
| 발췌가 원문에 없는 항목 | 21/86 = 24.4% | 18/78 = 23.1% |

1차판 결과.md에 0%로 찍힌 것은 윈도 경로의 역슬래시를 채점기가 정답표의 슬래시와 못 맞춘 탓. 원인: 유형을 제멋대로 붙임(엑사원은 할 일 대부분을 「현안」으로), 발췌를 고쳐 씀(엑셀 셀을 문장으로 재조립), 젬마는 발췌를 비움. 1차 모델 답을 2차판 채점(규칙층·근거 필터·유형 보정)에 통과시키면 엑사원 72.2%, 젬마 69.4%로 관문 경계. 2차 실측은 지시문을 고친 2차판으로 한다.

## 채점 기준(measure.py 2차판)

- **규칙층**: 「협의 담당: 이름(소속, 전화)」·전화번호 줄·「○월 ○일까지」 문장은 규칙으로 뽑는다(발췌 = 원문 줄). 모의 폴더에서 규칙만으로 정답 21/36(협의할 사람 13/14, 월별 할 일 8/16, 현안 0/6).
- **근거 없는 모델 항목은 초안에서 뺀다**: 발췌가 원문에 글자 그대로(띄어쓰기 무시) 또는 거의 그대로(2-gram 90% 이상) 없으면 「불확실(제외)」로 내린다. 신청서의 「발췌가 원문에 없는 항목은 불확실로 내리고 근거 없는 항목은 만들지 않는다」 그대로.

- **지어낸 항목**: 초안에 남은 항목 중 발췌가 원문에 없는 것. 2차판은 그런 항목을 초안에 넣지 않으므로 0이 정상이고, 대신 「모델이 낸 항목 중 뺀 비율」을 참고로 같이 적는다(모델 자체의 정확도). 관문 ②는 초안 기준 5% 이하.
- **출처까지 맞은 정답 항목**: 정답표의 항목과 같은 파일·같은 유형이고 요약 또는 발췌가 비슷하며(글자 2-gram 유사도 0.35 이상) 발췌가 원문에 있는 것. 관문 ②는 70% 이상.
- **시간**: 추출부터 초안까지 전체. 관문 ②는 20분 안.

## 확인된 것(2026-10-09, 리눅스)

- 모의 폴더 36개 중 34개 추출, 의도된 불량 3개(손상 .hwp·암호 PDF·스캔 jpg)는 사유 표시, 원본 변경 0. 추출 0.3초.
- 가짜 모델(정답 그대로)로 100% / 0%, 반만 맞는 가짜 모델로 63.9% / 59.6%가 나와 채점기가 구분한다.
- 실제 .hwp 파일은 이 환경에서 만들 수 없어 추출 코드만 규격대로 짰다. 한글에서 「시험」 한 줄짜리 .hwp를 저장해 `extract.py`로 읽어 보면 확인된다(실제 업무 문서는 쓰지 않는다).
- 만든 .hwpx는 실제 한글 문서의 꾸러미를 틀로 써서 만들었다. 한글에서 하나 열어 보이면 된다.
