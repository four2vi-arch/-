# 돌다리 소스 안내(개발자용) · v3.8

업무 인수인계 도우미 「돌다리」의 소스 설명입니다. 쓰는 방법과 심사용 안내는 저장소 첫 화면 `README.md`에 있습니다. 이 저장소의 시험 자료·정답표·예시 결과는 모두 합성 모의데이터입니다.

## 1. 소스로 실행하기

파이썬 3.10 이상이 있는 PC(윈도·리눅스, 3.12·3.13에서 확인)에서 씁니다. 파이썬이 없는 윈도 PC는 `실행물/`의 휴대용 묶음을 씁니다.

1. `소스/돌다리_소스_v3.8.zip`을 풀고 그 폴더로 갑니다. 저장소의 `소스/돌다리_실행.bat`·`실측.bat`·`부품목록.txt`는 zip 안에도 같은 것이 있으며, zip을 푼 폴더에서 써야 합니다.
2. 한 번만: `python -X utf8 -m pip install -r 부품목록.txt`(한국어 윈도에서 부품목록.txt의 한글 주석을 읽게 `-X utf8`를 붙입니다)
3. 윈도는 `돌다리_실행.bat`을 두 번 누르고, 그 밖에는 `python server.py`를 실행합니다. 브라우저에 `http://127.0.0.1:8765/`가 열립니다.

| 옵션 | 뜻 |
|---|---|
| `--port 8765` | 화면 포트. 다른 프로그램이 쓰고 있으면 8766~8775 가운데 빈 번호로 엶. 같은 작업 폴더의 돌다리가 이미 켜져 있으면 그 화면을 다시 열고 끝남 |
| `--work <폴더>` | 작업 폴더(세션·내보낸 파일). 기본은 `server.py` 옆 `작업`, 쓸 수 없으면 `%LOCALAPPDATA%\doldari\작업` |
| `--no-browser` | 브라우저를 자동으로 열지 않음 |
| `--allow-model-host 주소:포트` | 이 PC 밖 모델 서버(OpenAI 호환 `/v1/chat/completions`)를 허용 목록에 더함(여러 번 가능). 기관 모델 서버로 옮길 때 코드를 고치지 않고 쓰는 옵션이며, 이때 화면 ②에 키 칸이 나타나고 모델 목록은 Ollama `/api/tags`가 없으면 `/v1/models`로 읽음. 검은 창에 「이 PC 밖 주소」 경고를 찍음 |

부품(pypdf·olefile·openpyxl)이 없으면 화면 맨 위와 검은 창에 알립니다. 스캔 문서 OCR은 선택이며, 엔진 고르는 법은 `부품목록.txt`의 주석에 있습니다(윈도 내장 OCR용 winocr, RapidOCR, Tesseract). OCR은 그림 처리에 Pillow도 쓰는데 `부품목록.txt`에는 없으니 따로 설치합니다(휴대용 묶음에는 들어 있음).

## 2. 파일 구성과 역할

| 파일 | 하는 일 |
|---|---|
| `server.py` | 로컬 웹 서버(파이썬 표준 `http.server`). 127.0.0.1에만 열고 Host 머리를 검사함. 화면 API(`/api/extract`·`/api/draft`·`/api/items`·`/api/export` 등), 작업 상태를 작업 폴더 `세션.json`에 저장, 내보낼 때 원본을 다시 재고(`recheck_originals`) 원본지문 .csv를 씀. 두 번 실행 처리(`open_server`) |
| `extract.py` | 자체 추출기. hwp(한글 5.0, 옛 한글 2.x·3.x 어림 읽기)·hwpx·odt·ods·pdf·xlsx·docx·pptx·html·eml·txt·md·csv, zip 안 파일(임시 폴더에 풀어 읽음). 파일마다 읽기 전후 SHA-256. 못 읽은 파일은 사유와 함께 목록에. 단독 실행: `python extract.py <입력 폴더> <결과 폴더>` |
| `docs.py` | 문서 단위 처리. 문서 한 건 = 항목 한 개. 날짜·문서번호·제목·종류·업무·기한·담당·연락처를 규칙으로 읽고, 기준일과 기간(기본 12개월)으로 현안·반복·문서·연혁·현황을 나눔. 해마다 오는 문서는 지난 3년 파일 날짜로 반복 업무로. 누적 매뉴얼과 문서번호 대조, 개인 문서 빼기, 비밀번호 값 가리기. 모델(선택) 호출과 이어하기(`build_docs`) |
| `core.py` | 공통 부품. 모델 호출 `call_model`(OpenAI 호환, 유일한 호출 지점)과 주소 검사 `is_local_url`(허용 목록 `ALLOWED_MODEL_HOSTS`, `allow_model_host`로 더함), 기본 업무 키워드 `DEFAULT_AREAS`와 다른 기관용 보기 `AREA_PRESETS`(우편영업·지자체 서무·일반 행정), 업무 분류, 전화·기한·현안 신호어 규칙. measure.py가 쓰는 문장 단위 초안(`build_draft`)과 근거 확인 |
| `export.py` | 내보내기. 별지 제12호서식 차례의 .md, .docx(외부 패키지 없이 표준 라이브러리로 씀), 온나라 칸별 붙여넣기 .txt, 미리보기·인쇄용 HTML. 「(지남)」은 인계 일자 기준(비우면 오늘) |
| `ocr.py` | 스캔 PDF·그림 글자 읽기(선택). 윈도 내장 OCR → Tesseract → RapidOCR 가운데 있는 것. 결과는 작업 폴더 `ocr_cache`에 |
| `web/index.html`, `web/app.js` | 화면(외부 스크립트 없음) |
| `measure.py` | 실측·채점 도구(문장 단위). 모의 폴더와 정답표로 「출처까지 맞은 항목」·「지어낸 항목」을 셈. `--replay`로 모델 없이 다시 채점 |
| `make_mock.py`, `make_mock_v1.py` | 모의 폴더·정답표 생성기(가온우체국 2판, 한빛군청 1판). 가상 자료만 만듦 |
| `돌다리_실행.bat` | 윈도 실행. 휴대용 묶음이면 내장 파이썬, 아니면 설치된 `python`·`py -3` 순으로 찾음 |
| `실측.bat` | 윈도에서 measure.py를 한 번에 실행(같은 폴더에 `가온우체국_모의업무폴더`와 `정답표.xlsx`를 둠) |
| `부품목록.txt` | pip 부품 목록(서버 검사 때문에 `requirements.txt` 대신 이 이름) |
| `도구/` | `make_portable.py`(휴대용 묶음), `make_gitlab_upload.py`(GitLab 올림 폴더), `make_example_outputs.py`(예시결과), `gitlab_hook_sim.py`(올리기 전 서버 검사 흉내), `build_odt.py`·`build_hwpx.py`·`template.hwpx`(모의 공문·보고서 생성) |
| `시험/` | 자동 시험(아래 4절). `fake_ollama.py`는 시험용 가짜 모델 서버, `winlike_run.py`는 윈도식 포트 동작 흉내 |

## 3. 처리 흐름

1. **읽기**(`extract.extract_folder`): 폴더 → 파일 목록(파일·형식·수정일·글자 조각), 못 읽은 파일(사유), 파일별 SHA-256(처리 전·후).
2. **분류·기한·반복·현안 규칙**(`docs.plan_docs`): 기준일(인계 일자, 비우면 오늘, 폴더가 90일 넘게 지난 사본이면 마지막 문서 다음 날)과 기간을 정하고, 문서마다 종류·업무·기한·담당을 읽어 현안 후보·반복 업무·관련 문서·연혁·현황으로 나눕니다.
3. **초안**(`docs.build_docs`): 현안·반복 문서에는 기한·미결·후임 같은 말이 든 원문 줄을 그대로 붙이고, 미결·할 일을 제안합니다.
4. **선택 모델 요지**(`docs.build_docs` → `core.call_model`): 현안 후보 문서마다 한 번, 제목과 앞 4천 자(`server.py` `MAX_CHARS3`)를 보내 요지·할 일·기한·담당·상태 JSON을 받습니다. 기한은 문서에서 찾은 기한 가운데 하나일 때만, 담당은 그 이름·전화가 원문에 있을 때만 씁니다. 응답은 호출마다 작업 폴더 `모델응답_이어하기.jsonl`에 적어, 같은 폴더·모델이면 다음에 다시 부르지 않습니다. 5회 연속 실패하면 남은 문서는 규칙만으로 끝냅니다.
5. **전임자 확인**(화면 → `server.py` `/api/items`): 넣기·버리기·상태·메모·직접 적기를 `세션.json`에 남깁니다. 폴더를 다시 읽거나 초안을 다시 만들어도 사람이 정한 것은 남습니다.
6. **내보내기**(`/api/export` → `export.write_all`): 원본을 다시 재어 원본지문 .csv를 쓰고, .docx·.md·온나라 .txt를 작업 폴더에 만듭니다.

모델 주소는 기본으로 이 PC(127.0.0.1·localhost·::1)만 받고, `--allow-model-host`로 더한 주소(`core.ALLOWED_MODEL_HOSTS`)도 받습니다. 기관 서버로 옮길 때 더 볼 곳은 첫 화면 README 「정보화사업 이관」에 있습니다.

## 5. 실측결과 다시 채점하기(모델 없이)

`실측결과.zip`에는 2종 모델(젬마 3 4B·엑사원 3.5 7.8B) 실측 원자료가 있습니다. 폴더마다 `결과.md`(판정표)와 `결과.json`(모델이 낸 항목 포함)이 있습니다.

1. 소스 zip을 푼 폴더에 `실측결과.zip`과 `모의데이터_v1_한빛군청.zip`을 풉니다. 두 압축 안에는 같은 이름 폴더가 이미 들어 있습니다. 윈도 「압축 풀기」 창에서 대상 폴더를 소스 폴더로 고치고, 끝에 저절로 붙는 압축 이름은 지웁니다.
2. 그 폴더에 `모의데이터` 폴더를 만들고, 대상 폴더를 `모의데이터`로 해서 `가온우체국_모의업무폴더.zip`을 같은 방법으로 풉니다. 이어서 `정답표.xlsx`를 같은 `모의데이터` 폴더에 둡니다. `모의데이터/가온우체국_모의업무폴더` 바로 아래에 `01_공문` 등이 보여야 합니다. 같은 이름 폴더가 두 겹이면 파일 경로가 정답표와 달라 채점이 맞지 않습니다.
3. 실행:

```
python measure.py 모의데이터/가온우체국_모의업무폴더 모의데이터/정답표.xlsx 재채점_젬마 --model replay --replay 실측결과/4차_gemma_정답표보정재채점/결과.json
python measure.py 모의데이터/가온우체국_모의업무폴더 모의데이터/정답표.xlsx 재채점_엑사원 --model replay --replay 실측결과/4차_exaone_정답표보정재채점/결과.json
python measure.py 모의데이터/가온우체국_모의업무폴더 모의데이터/정답표.xlsx 재채점_규칙만 --model none
python measure.py 모의데이터_v1_한빛군청/가상기관_모의업무폴더 모의데이터_v1_한빛군청/정답표.xlsx 재채점_한빛_엑사원 --model replay --replay 실측결과/3차_exaone/결과.json
```

v3.7.3 코드로는 가온 젬마 30/33·엑사원 29/33·규칙만 29/33, 한빛 엑사원 32/36이 나오고 지어낸 항목은 0입니다(10.22.). 처리 시간·호출 수는 실측 때 값을 그대로 적습니다. 모델을 직접 부르려면 `--model gemma3:4b`처럼 모델 이름을 주고 `--replay`를 뺍니다(`--url`로 주소, 기본은 Ollama). 윈도에서는 bat과 같은 폴더에 `가온우체국_모의업무폴더`와 `정답표.xlsx`를 두고 `실측.bat gemma3:4b "PC 사양"`으로도 됩니다.

## 6. 묶음 만들기(개발자)

**휴대용 묶음**(윈도 64비트, 파이썬 내장): 인터넷 되는 PC에서 부품 설치 파일(wheel)과 파이썬 nupkg를 한 번 받아 둡니다.

```
pip download --only-binary=:all: --platform win_amd64 --python-version 3.12 --implementation cp -d wheels olefile pypdf openpyxl pypdfium2 Pillow winocr
(파이썬 nupkg: https://api.nuget.org/v3-flatcontainer/python/3.12.10/python.3.12.10.nupkg)
python 도구/make_portable.py --nupkg python.3.12.10.nupkg --wheels wheels --out <출력 폴더>
```

결과는 `doldari_v<판>_portable_win64.zip`입니다. 안의 구성은 `doldari/run.bat`(같은 내용의 `돌다리_실행.bat`도 둠)·`python/`(CPython과 부품)·`app/`(돌다리 소스)·`README.txt`입니다.
