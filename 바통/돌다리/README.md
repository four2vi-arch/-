# 돌다리 v1.0 · 추출층·모의 업무폴더·관문 ② 실측 도구(2026-10-10)

세션2 지정과제① 업무바통(인수인계) 출품작 「돌다리」의 첫 조각이다. 10.20. 관문을 앞당겨 재기 위해 추출기·모의 업무폴더·정답표·실측 스크립트를 먼저 만들었다. 검토 화면·내보내기 등 나머지는 실측 결과를 본 뒤 만든다.

| 파일 | 하는 일 |

## 실측 순서(미니PC, 10.10.~10.11.) · 3차는 결과 폴더 이름만 `결과3_…`으로

1. Ollama를 설치한다(ollama.com → Download for Windows). 설치 뒤 명령 프롬프트에서 모델 2종을 받는다(합쳐 약 8GB, 인터넷 필요).
   ```
   ollama pull exaone3.5:7.8b
   ollama pull gemma3:4b
   ```
2. 이 폴더(`돌다리_실측`)를 바탕화면에 풀어 둔다. 안에 `가상기관_모의업무폴더`와 `정답표.xlsx`가 있다.
3. 폴더에서 주소창에 `cmd`를 치고 아래를 차례로 실행한다. 첫 줄은 패키지 설치(한 번만), 둘째·셋째 줄이 모델별 실측이다. 각 실측은 파일 34개에 모델을 34번 부르므로 CPU에서 10~30분 걸릴 수 있다. 끝나면 결과표가 화면에 찍히고 `결과_모델이름\결과.md`에 남는다.
   ```
   python -m pip install -r requirements.txt
   python measure.py 가상기관_모의업무폴더 정답표.xlsx 결과3_exaone --model exaone3.5:7.8b --label "Ryzen 7 6800H 8코어 28GB CPU"
   python measure.py 가상기관_모의업무폴더 정답표.xlsx 결과3_gemma --model gemma3:4b --label "Ryzen 7 6800H 8코어 28GB CPU"
   ```
4. `결과3_exaone\결과.md`·`결과.json`, `결과3_gemma\결과.md`·`결과.json`과 각 폴더의 `인수인계_초안.md`를 보내 주면 관문 ②를 확정한다.

모델 없이 배관만 확인하려면 `python measure.py 가상기관_모의업무폴더 정답표.xlsx 결과_점검 --model fake`(정답을 그대로 돌려주는 가짜 모델, 100%가 나와야 정상).

## 1차 실측(10.9. 밤, 미니PC Ryzen 7 6800H·28GB·CPU, 1차판 measure.py)

| | 엑사원 3.5 7.8B | 젬마 3 4B |
|---|---|---|
| 처리 시간(34개 파일, 호출 34회) | 754.8초(평균 22.2초) | 686.5초(평균 20.2초) |
| 출처까지 맞은 정답 항목(경로 표기 고쳐 재채점) | 13/36 = 36.1% | 16/36 = 44.4% |
| 발췌가 원문에 없는 항목 | 21/86 = 24.4% | 18/78 = 23.1% |

1차판 결과.md에 0%로 찍힌 것은 윈도 경로의 역슬래시를 채점기가 정답표의 슬래시와 못 맞춘 탓. 원인: 유형을 제멋대로 붙임(엑사원은 할 일 대부분을 「현안」으로), 발췌를 고쳐 씀(엑셀 셀을 문장으로 재조립), 젬마는 발췌를 비움. 1차 모델 답을 2차판 채점(규칙층·근거 필터·유형 보정)에 통과시키면 엑사원 72.2%, 젬마 69.4%로 관문 경계. 2차 실측은 지시문을 고친 2차판으로 한다.

결과 파일: `실측결과/2차_exaone/`·`2차_gemma/`(미니PC 원본), `2차_*_3차판재채점/`(이 저장소에서 `--replay`로 다시 채점), `규칙층만_3차판/`.

2차에서 놓친 11건의 원인과 3차판에서 고친 것
- **맞는데 못 맞춘 것**(5건): 모델이 정답과 같은 줄을 집었는데 요약 말이 달라 2-gram 유사도 0.35를 못 넘김(예: 「8월 한 달간 냉방 26도 유지」). 3차판은 발췌 줄이 서로 포함되거나 짧은 쪽이 긴 쪽에 60% 이상 담기면 적중으로 본다.
- **규칙이 못 잡던 기한 표현**(4건): 「5월 말까지」·「제출 1주 전」·「만료 2개월 전」·「제출일 2025-09-11」. 3차판 규칙층이 잡는다.
- **현안**(2차 2/6·0/6): 메모·메일의 「미조치·반려·안 됨·재협의 중」 문장. 3차판은 현안 신호어 줄을 규칙으로 뽑는다(3/6). 나머지 3건(엑셀 집행률 71%, 메일 「195,000원 요구」, 반려 메일 본문)은 숫자·문맥 해석이 필요해 규칙·모델 모두 못 잡음.
- **빈 발췌·고쳐 쓴 발췌**: 모델이 발췌를 비우거나(젬마 64건) 문장을 다듬어 씀(「…갱신합니다」↔「…갱신한다」). 3차판은 원문 한 줄과 70% 이상 겹치면 그 원문 줄로 바꿔 넣고 「발췌 보정」으로 표시한다. 그래도 근거를 못 찾으면 종전처럼 「불확실(제외)」.
- 전화번호 줄의 이름 고르기(「복합기 · …」처럼 엉뚱한 낱말이 이름이 되던 것) 고침.

**솔직한 한계**: 모의 폴더·정답표·규칙이 모두 같은 사람(이 대화)의 손에서 나왔다. 규칙층만으로 80.6%가 나오는 것은 이 모의 폴더의 기한·담당 표기가 규칙에 잘 맞기 때문이며, 실제 기관 문서에서는 낮아질 수 있다. 3차판 규칙(「○월 말까지」·현안 신호어 등)은 특정 정답을 겨냥한 것이 아니라 행정 문서에 흔한 표현이지만, 실제 문서로 한 번 더 재는 것(10.19. 최소판 재측정)이 진짜 시험이다. 「발췌 보정」은 모델이 뜻을 잘못 읽은 항목에 실제 줄을 붙일 수도 있으므로(젬마의 「구매대장 날짜 = 기한」 오독 등) 초안에 표시를 남기고, 「초안 항목 중 정답에 없는 것」 비율을 함께 적는다.

|---|---|---|---|
| 처리 시간(34개 파일, 호출 34회) | 738.3초(평균 21.7초) | 733.8초(평균 21.6초) | 1,200초 안 |

| 유형별(할 일/사람/현안) | 15/16 · 14/14 · 3/6 | 14/16 · 14/14 · 3/6 | |
| 초안에 든 지어낸 항목 | 0/83 | 0/97 | 5% 이하 |
| 초안 항목 중 정답에 없는 것(전임자가 지울 몫) | 50/83 | 63/97 | (참고) |
| 모델 항목 중 뺀 것 / 발췌 보정 | 8/23 · 4/23 | 37/66 · 16/66 | (참고) |
| 오류 | 없음 | 없음(2차의 HTTP 500 2건은 재시도 없이도 안 남) | |

재채점 예상치(88.9%·86.1%)와 같은 값이 나왔다. 놓친 것은 2차와 같은 4~5건(「5월 말까지」 정답 발췌와 규칙이 집은 줄이 다름, 엑셀 집행률 71%, 반려 메일 본문, 「195,000원 요구」 메일, 젬마는 소방점검 1건 더). 결과 파일: `실측결과/3차_exaone/`·`3차_gemma/`.

**남은 품질 과제(최소판에서)**: 초안의 절반 이상이 정답표에 없는 항목(엑셀 구매대장 줄을 「기한」으로 읽은 젬마의 오독 등)이라 검토 화면에서 전임자가 지우기 쉬워야 한다. 현안은 규칙·모델 모두 3/6에 머무르므로 검토 화면에 「현안 직접 적기」 칸이 필요하다.

## 채점 기준(measure.py 3차판)

- **규칙층**: 「협의 담당: 이름(소속, 전화)」·전화번호 줄(이름은 「이름 담당/과장…」 또는 번호 앞 낱말)·기한 문장(「○월 ○일/말/초까지」·「○월 ○일~○일」·「2025-09-11」+제출/기한·「○개월/○주 전」)·현안 신호어 줄(미조치·미결·반려·보류·지연·끝나지 않음·안 됨·재협의·고장·누수…)은 규칙으로 뽑는다(발췌 = 원문 줄). 모의 폴더에서 규칙만으로 29/36(사람 14/14, 할 일 12/16, 현안 3/6). 2차판은 21/36이었다.
- **근거 없는 모델 항목은 초안에서 뺀다**: 발췌가 원문에 글자 그대로(띄어쓰기 무시) 또는 거의 그대로(2-gram 90% 이상) 있으면 그대로 싣는다. 원문 한 줄(이어진 두 줄 포함)과 70% 이상 겹치면 그 줄로 바꿔 「발췌 보정」 표시, 발췌가 비었으면 요약이 한 줄과 70% 이상 겹칠 때만 그 줄을 붙인다. 그 밖은 「불확실(제외)」로 내린다. 신청서의 「발췌가 원문에 없는 항목은 불확실로 내리고 근거 없는 항목은 만들지 않는다」 그대로.

- **지어낸 항목**: 초안에 남은 항목 중 발췌가 원문에 없는 것. 2차판은 그런 항목을 초안에 넣지 않으므로 0이 정상이고, 대신 「모델이 낸 항목 중 뺀 비율」을 참고로 같이 적는다(모델 자체의 정확도). 관문 ②는 초안 기준 5% 이하.
- **출처까지 맞은 정답 항목**: 정답표의 항목과 같은 파일·같은 유형이고, 발췌 줄이 서로 포함되거나 요약·발췌가 비슷하거나(글자 2-gram 유사도 0.35 이상) 짧은 쪽이 긴 쪽에 60% 이상 담기며, 발췌가 원문에 있는 것. 관문 ②는 70% 이상.
- **시간**: 추출부터 초안까지 전체. 관문 ②는 20분 안.
