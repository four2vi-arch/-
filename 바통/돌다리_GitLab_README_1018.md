# 돌다리: 출처 달린 인수인계 초안을 전임자가 두드려 보고 넘기는 업무 인수인계 도우미

> 2026년 공공 AI 대전환 챌린지 · 세션2(지정과제 업무바통) · 정읍우체국 영업과 이희재 · v3.7.3(2026-10-22)

전임자의 업무 폴더(공문 ODT·한글·PDF·엑셀·워드·메일·메모)를 폴더째 읽어, 법정 서식(「행정업무의 운영 및 혁신에 관한 규정 시행규칙」 별지 제12호서식 업무인계·인수서) 차례대로 담당 업무·반복 업무·현안·미결·관련 문서·연락처 초안을 만듭니다. 제안한 줄마다 근거 문서가 붙고, 기한·미결 같은 말이 든 원문 줄이 있으면 그 줄을 글자 그대로 함께 붙입니다. 전임자는 화면에서 넣기·버리기·고치기를 한 뒤 워드(.docx)·마크다운(.md)·온나라 붙여넣기 글로 내보냅니다. 원본은 읽기만 합니다. 돌다리 화면과 처리는 이 PC 안(127.0.0.1)에서만 돌고, AI 모델도 이 PC 주소만 받습니다. AI 모델은 선택이며, 없어도 규칙만으로 끝까지 동작합니다.

## 접속 주소

**따로 접속할 주소가 없는 PC용 프로그램입니다.** 서버 주소나 로그인 계정이 필요 없습니다. 휴대용 zip을 풀고 `돌다리_실행.bat`을 두 번 누르면, 그 PC의 브라우저에 `http://127.0.0.1:8765/`(「이 PC」를 뜻하는 주소)가 열립니다. 이 주소는 실행한 PC에서만 열립니다. 파이썬 설치와 인터넷도 필요 없습니다(AI 모델을 함께 쓸 때만 「LLM 연결 설정」의 준비가 필요합니다).

## 실행·작동 방법

### 실행

1. `실행물/doldari_v3.7.3_portable_win64.zip`(윈도 10·11 64비트, 14,982,630바이트·약 15MB, 파이썬 3.12 내장)을 내려받아 바탕화면 등에 압축을 풉니다. 압축 파일 안에서 바로 실행하지 않습니다.
2. 풀린 `doldari` 폴더의 `돌다리_실행.bat`(또는 `run.bat`)을 두 번 누릅니다. 「Windows의 PC 보호」 창이 뜨면 「추가 정보 → 실행」을 누릅니다.
3. 브라우저에 `http://127.0.0.1:8765/`가 저절로 열립니다(8765를 다른 프로그램이 쓰고 있으면 8766~8775 가운데 빈 번호). 끝낼 때는 검은 창을 닫습니다.

휴대용 zip의 SHA-256: `54e5754ce0ba77b6a7becda1faed079dc5844f7511afcde5cd1eaba4e3f84307`(윈도 명령 창에서 `certutil -hashfile doldari_v3.7.3_portable_win64.zip SHA256`으로 확인).

### 작동: 모의 폴더로 해 보기(핵심 흐름)

1. `모의데이터/가온우체국_모의업무폴더.zip`을 풀고, 화면 ①에 그 폴더 주소를 붙여 넣거나 「목록에서 고르기」 → **읽기**. 읽은 문서 41 · 못 읽은 문서 2 · 읽지 않는 형식 1 · 원본 변경 0이 나옵니다.
2. ② **초안 만들기**(규칙만이면 몇 초). 왼쪽 1-가에서 인계자·인수자·입회자와 **일자 2026-03-02**를 적고 ②에서 초안 만들기를 한 번 더 누릅니다(넣기·버리기 결정은 남음). 이 일자로 하면 `예시결과/`와 같은 기준일이 됩니다.
3. 1-다 현안: 줄마다 「원문 ▸」로 근거 줄을 보고 **넣기·버리기**, 상태·다음에 할 일을 적습니다.
4. 오른쪽 위 **「인계·인수서 내려받기」** → 「워드 파일(.docx) 받기」. 「작업 폴더 열기」로 .docx·.md·온나라 .txt·원본지문 .csv를 확인합니다.

## 주요 기능

- **폴더째 읽기**: 형식이 섞인 폴더를 한 번에 읽고, 못 읽은 파일은 건너뛰지 않고 사유를 남깁니다.
- **서식 차례 초안**: 1-가 담당 업무(업무별 연혁·현황 자료), 1-나 주요 업무계획(인수 직후 할 일, 해마다·매월·매주 되풀이되는 업무), 1-다 현안, 1-라 미결, 2 관련 문서, 3 물품·예산(직접 적기), 4 연락처·누적 매뉴얼 대조. 끝에 「위와 같이 인계·인수합니다」와 서명란.
- **전임자 검토**: 표로 보기·카드로 보기에서 넣기·버리기, 한 업무를 한꺼번에 정리, 직접 적기.
- **받는 사람 보기**: 화면 위 「넘기는 사람·받는 사람」 전환. 결과물에 「인수 확인」 ☐ 칸과 「인수자 질문·전임자 답」 표.
- **내보내기**: .docx(표 머리행이 쪽마다 반복), .md, 온나라 칸별 붙여넣기 글, 원본지문 .csv. 인쇄·미리보기.
- **안정성**: 두 번 실행해도 같은 화면을 다시 엽니다. 파일 하나가 깨져도 그 파일만 사유를 남기고 계속합니다. 모델 응답은 호출마다 저장해 끊겨도 이어서 합니다.
- **AI(선택)**: 현안 후보 문서마다 「요지·할 일」 한 줄(「모델 비종속」).

## 기대효과

- 인수인계서에 잘 담기지 않던 실제 일정(기한·반복 업무)·협의관계(연락처)·진행상황(현안·미결)이 문서에서 바로 제안됩니다. 전임자는 빈 서식을 처음부터 채우지 않고 제안된 줄을 넣고 버립니다.
- 줄마다 근거 문서가 붙어 있어, 후임자가 과거 문서를 다시 찾거나 주변에 묻는 일을 줄이는 것을 목표로 합니다(효과는 아직 재지 않았습니다).
- 설치·서버·인터넷이 필요 없어 어느 기관 PC에서나 압축만 풀어 씁니다. 모델이 없는 PC에서도 같은 서식의 결과가 나옵니다.

## 모델 비종속: 2종 모델 구동 결과

돌다리는 모델을 OpenAI 호환 `/v1/chat/completions` 주소 한 곳으로만 부릅니다(`core.py`의 `call_model`). 모델을 바꿀 때는 화면에서 모델 이름만 고르며, 코드는 고치지 않습니다. 모델이 없거나 5회 연속 응답하지 않으면 남은 문서는 규칙만으로 끝까지 만듭니다. 근거 줄(원문 발췌)은 언제나 규칙이 원문에서 그대로 가져오고, 모델은 현안 후보 문서마다 「요지·할 일」 한 줄을 보탭니다. 시험한 두 모델(젬마·엑사원)은 참가 안내서 6절에 적힌 행정안전부 AI 공통기반 지원 모델 계열입니다.

- 화면(문서 단위)은 같은 `call_model`로 현안 후보 문서마다 요지·할 일을 받습니다. 위 표는 measure.py(문장 단위) 경로로 잰 값입니다.

**모델 없이 다시 채점하기**(Ollama 없이, 파이썬 3.10 이상이 있는 PC)

1. 빈 폴더 하나(예: `C:\돌다리`)를 대상으로 `소스/돌다리_소스_v3.7.3.zip`을 풉니다. `server.py`·`measure.py`가 그 폴더 바로 아래에 보여야 합니다.
2. 같은 폴더에 `소스/실측결과.zip`과 `소스/모의데이터_v1_한빛군청.zip`을 풉니다. 두 압축 안에는 `실측결과`·`모의데이터_v1_한빛군청` 폴더가 이미 들어 있습니다. 윈도 「압축 풀기」 창에서 대상 폴더를 `C:\돌다리`로 고치고, 끝에 저절로 붙는 압축 이름은 지웁니다.
3. 그 폴더에 `모의데이터` 폴더를 만들고, 대상 폴더를 `C:\돌다리\모의데이터`로 해서 `모의데이터/가온우체국_모의업무폴더.zip`을 같은 방법으로 풉니다. 저장소의 `모의데이터/정답표.xlsx`도 그 폴더에 넣습니다. `모의데이터\가온우체국_모의업무폴더` 바로 아래에 `01_공문`~`08_연도별_공문` 8개 폴더가 보여야 합니다. 같은 이름 폴더가 한 겹 더 있으면 파일 경로가 정답표와 달라 채점이 맞지 않습니다.
4. 명령 창에서 그 폴더로 가서 한 번만 `python -X utf8 -m pip install -r 부품목록.txt`를 실행합니다(한국어 윈도에서 부품목록.txt의 한글 주석을 읽게 `-X utf8`를 붙입니다).
5. 다음을 실행하면 지정한 결과 폴더에 `결과.md`가 생깁니다.

```
python measure.py 모의데이터/가온우체국_모의업무폴더 모의데이터/정답표.xlsx 재채점_젬마 --model replay --replay 실측결과/4차_gemma_정답표보정재채점/결과.json
python measure.py 모의데이터/가온우체국_모의업무폴더 모의데이터/정답표.xlsx 재채점_규칙만 --model none
python measure.py 모의데이터_v1_한빛군청/가상기관_모의업무폴더 모의데이터_v1_한빛군청/정답표.xlsx 재채점_한빛_엑사원 --model replay --replay 실측결과/3차_exaone/결과.json
```

가온 엑사원은 `실측결과/4차_exaone_정답표보정재채점/결과.json`, 한빛 젬마는 `실측결과/3차_gemma/결과.json`을 넣습니다.

## 원본 보호와 확인 방법

- **읽기만 함**: 파일마다 읽기 직전·직후 SHA-256을 재고(`extract.py` `extract_folder`), 내보낼 때 한 번 더 잽니다(`server.py` `recheck_originals`). zip 안 파일은 운영체제 임시 폴더에 풀어 읽고 끝나면 지웁니다(원본 zip은 그대로).
- **산출물은 따로**: 업무 폴더가 아니라 작업 폴더에 씁니다. 휴대용은 `doldari\app\작업\`(그곳에 쓸 수 없으면 `%LOCALAPPDATA%\doldari\작업`), 소스 실행은 `작업\` 또는 `--work`로 정한 폴더입니다.
- **증빙**: 내보낼 때마다 `인수인계서_날짜_시각_원본지문.csv`(파일·바이트·처리 전 SHA-256·내보낼 때 SHA-256·변경 없음)를 만들고, 인수인계서 끝에 「원본 변경 0개(처리 전후 SHA-256 대조)」를 적습니다.
- **확인 방법**: 원본지문 .csv를 엑셀로 열어 「변경 없음」 열이 모두 「예」인지 봅니다. 따로 확인하려면 `certutil -hashfile <파일> SHA256`으로 잰 값을 「처리 전 SHA-256」과 비교합니다. 예시: `예시결과/예시_원본지문.csv`(모의 폴더 43개 파일 모두 「예」).

## 정보화사업 이관: 구조와 바꿀 곳

| 단계 | 파일·함수 | 입력 → 출력 |
|---|---|---|
| 읽기 | `extract.py` `extract_folder` | 폴더 → 파일 목록(파일·형식·수정일·글자 조각), 못 읽은 파일(사유), 파일별 SHA-256 |
| 분류·기한·반복·현안 | `docs.py` `plan_docs`·`build_docs` | 파일 목록 → 문서 항목(문서 한 건 = 항목 한 개: 날짜·문서번호·제목·업무·기한·담당·반복·현안/미결) |
| 모델(선택) | `docs.py` `build_docs` → `core.py` `call_model` | 문서 제목과 앞 4천 자 → 요지·할 일·기한·담당 JSON |
| 검토 화면 | `server.py`(파이썬 표준 `http.server`) + `web/` | 넣기·버리기·메모 → 작업 폴더 `세션.json` |
| 내보내기 | `export.py` `write_all`, 원본지문은 `server.py` | 세션 → .docx·.md·온나라 .txt, 원본지문 .csv |
| 스캔 문서(선택) | `ocr.py` | 스캔 PDF·그림 → 글자 |

꼭 필요한 외부 부품은 olefile·pypdf·openpyxl 셋입니다. 스캔 문서 OCR에는 pypdfium2·Pillow와 OCR 엔진이 더 필요합니다. `부품목록.txt`에는 pypdfium2까지만 있고(OCR 엔진은 주석), 휴대용 묶음에는 pypdfium2·Pillow·winocr(윈도 내장 OCR 연결)가 들어 있습니다. 웹 프레임워크·DB가 없고, 모델 호출은 `call_model` 한 곳뿐입니다.

이관 때 바꿀 곳(지금 판은 개인 PC용이라 일부러 막아 두었습니다):

1. **기관 내부 모델 서버**(OpenAI 호환 주소를 주는 경우): `core.py` `is_local_url` 한 곳에 허용 주소를 더합니다. 화면 설정(`server.py` `/api/settings`)·모델 목록(`ollama_models`)·채점 도구(`core.build_draft`)가 모두 이 함수를 부릅니다. `/api/settings`의 거절 안내 문구도 함께 고칩니다. 127.0.0.1 제한은 문서가 PC 밖으로 나가지 않게 하려고 둔 것입니다.
2. **API 키**: `core.call_model`은 키를 받아 `Authorization: Bearer`로 보내지만, 화면은 키를 넘기지 않습니다(`server.py` `run_draft`). 설정 항목 하나를 더하면 됩니다.
3. **모델 목록**: `server.py` `ollama_models`가 Ollama `/api/tags`만 읽습니다. OpenAI 호환 `/v1/models` 읽기를 더합니다.
4. **여러 사용자 서버**: 지금은 한 사람·한 작업 폴더(`세션.json`)이고, 화면 서버는 127.0.0.1에만 열리며 Host 머리를 검사합니다(`server.py` `open_server`·`_ok_host`). 사용자별 작업 폴더와 접속 허용 범위를 바꿉니다.
5. **문서시스템 API 연계**: 구현하지 않았습니다. 수집기가 `extract_folder`와 같은 꼴(파일 목록, 못 읽은 파일, 지문)을 돌려주면 분류 단계부터 그대로 씁니다.

## 알려진 제약

- 휴대용 묶음은 윈도 10·11 64비트 전용입니다. 소스는 파이썬 3.10 이상이 필요하고, 3.12(휴대용 묶음)·3.13(리눅스)에서 확인했습니다.
- 한 사람이 자기 PC에서 쓰는 구조입니다. 받는 사람은 내보낸 .docx 등 파일로 받습니다.
- 모델은 이 PC(127.0.0.1·localhost·::1)의 OpenAI 호환 주소만 받고, 화면에 키 칸이 없습니다. 모델 목록은 Ollama 방식으로 가져옵니다.
- 모델의 요지·할 일은 원문과 글자 대조를 하지 않습니다(기한·담당만 원문에 있을 때 채택). 「AI 요지」 표시를 보고 전임자가 원문으로 확인해야 합니다.
- 모델은 CPU에서 호출당 평균 21.6~26.6초 걸렸습니다(위 실측).
- 스캔 문서 글자 읽기는 이 PC에 OCR 엔진(윈도 내장 OCR의 한국어 「광학 문자 인식」, Tesseract, RapidOCR)이 있을 때만 됩니다. 한국어 인식 품질은 PC마다 다릅니다.
- 못 읽는 것: 한셀(.cell)·한쇼(.show)·.rtf, 옛 .doc·.xls·.ppt(새 형식으로 다시 저장 안내), 암호 걸린 파일, 글자를 찾지 못한 옛 한글 2.x·3.x 문서, OCR이 없을 때의 스캔 PDF. 모두 붙임 2에 사유를 남깁니다.
- 규칙 중심이라 숫자 해석이 필요한 현안(예: 누계 달성률), 같은 사안이 공문·메일·메모로 나뉜 경우의 묶기, 문서 사이 내용 충돌은 잡지 못합니다.
- 기본 업무 키워드는 우편영업 예시입니다. 다른 기관은 폴더 이름으로 나누거나 「업무 키워드」를 고쳐 씁니다.
- 문서시스템 API 연계는 구현하지 않았습니다. 온나라 붙여넣기 글을 실제 온나라 인계서 화면에 붙이는 것은 기관 PC에서 확인이 필요합니다.
- 모의 폴더·정답표·규칙을 같은 개발 과정에서 만들었으므로, 모의 폴더 수치는 실제 기관 문서보다 높게 나올 수 있습니다.
