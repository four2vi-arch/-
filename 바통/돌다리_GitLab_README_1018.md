# 돌다리: 출처 달린 인수인계 초안을 전임자가 두드려 보고 넘기는 업무 인수인계 도우미

> 2026년 공공 AI 대전환 챌린지 · 세션2(지정과제 업무바통) · 정읍우체국 영업과 이희재 · v3.6(2026-10-18)

전임자의 업무 폴더(공문 ODT·한글·PDF·엑셀·워드·메일·메모)를 읽어 법정 서식(「행정업무의 운영 및 혁신에 관한 규정 시행규칙」 별지 제12호서식 업무인계·인수서) 차례대로 담당 업무·반복 업무·현안·미결·관련 문서·연락처 초안을 만들고, 전임자가 화면에서 넣기·버리기·고치기를 한 뒤 워드(.docx)·마크다운·온나라 붙여넣기 글로 내보냅니다. 문서마다 출처 파일을 붙이고, 원본은 읽기만 하며(처리 전후·내보낼 때 SHA-256 대조), 모든 처리는 이 PC 안(127.0.0.1)에서 끝납니다. AI 모델은 선택이며 없어도 규칙만으로 동작합니다.

## 접속 주소

서버·계정이 없습니다. `실행물/doldari_v3.6_portable_win64.zip`(윈도 10·11, 64비트, 파이썬 내장)을 내려받아 압축을 풀고 `돌다리_실행.bat`(또는 `run.bat`)을 누르면 브라우저에 `http://127.0.0.1:8765/`가 열립니다. 파이썬 설치·인터넷이 필요 없습니다.

## 주요 기능

- **폴더 한 번에 읽기**: ODT·hwpx·한글 5.0/옛 한글 97·PDF(스캔은 윈도 내장 OCR 선택)·docx·xlsx·csv·eml·txt·md·zip 안 파일까지. 못 읽은 파일은 사유와 함께 붙임에 남김.
- **서식 차례대로 초안**: 1-가 담당 업무(업무별 연혁·현황 자료), 1-나 해마다·매월 되풀이되는 업무(지난 3년 파일 날짜로 찾음), 1-다 현안(기한·미결·보류 말), 1-라 미결, 2 관련 문서, 3 물품·예산(직접 적기), 4 연락처·누적 매뉴얼 대조(★ 미반영 공문). 끝에 「위와 같이 인계·인수합니다」·서명란.
- **전임자가 두드려 보기**: 줄마다 「원문 ▸」로 원문 앞부분과 기한·미결 줄을 보고 넣기·버리기, 상태·다음 할 일·메모, 직접 적기. 넣기 전 제안은 「[확인 전]」으로 표시돼 빠뜨리지 않음. 다시 읽거나 다시 만들어도 결정은 남음.
- **내보내기**: .docx(진짜 표·머리행 반복), .md, 온나라 칸별 붙여넣기 글, 원본지문.csv(내보낼 때 원본을 다시 재어 변경 여부 증빙). 인쇄·미리보기.
- **AI(선택, 모델 비종속)**: 이 PC의 Ollama(OpenAI 호환 주소, 127.0.0.1만 허용)로 현안 후보마다 「요지·할 일」 한 줄. 모델이 낸 담당자·기한은 원문에 있을 때만 채택.

## 실행·작동 방법

1. `실행물/`의 zip을 바탕화면 등에 **압축 풀기**(압축 안에서 바로 실행하지 않기) → `doldari\돌다리_실행.bat` 두 번 누르기(「Windows의 PC 보호」 창이면 「추가 정보 → 실행」). 끝낼 때는 검은 창을 닫습니다.
2. `모의데이터/가온우체국_모의업무폴더.zip`을 풀고, 화면 ①에 그 폴더 주소를 붙여 넣거나 「목록에서 고르기」 → **읽기**.
3. ② **초안 만들기**(규칙만이면 몇 초) → 자동으로 「1-다 현안사항」 → 「원문 ▸」을 보며 넣기·버리기, 상태·다음에 할 일.
4. 1-가에 인계자·인수자·입회자와 업무 한 줄 설명, 3절 물품·예산 → 오른쪽 위 **「인계·인수서 내려받기」** → 「워드 파일(.docx) 받기」, 「작업 폴더 열기」.
5. (선택) AI: Ollama 설치 → `ollama pull exaone3.5:7.8b` 또는 `ollama pull gemma3:4b` → ②에서 「AI 모델도 사용」 → 모델 고르기. 모델 이름만 바꾸면 다른 모델로 바뀝니다.

## 자료·오픈소스

- 모의데이터는 모두 가상(기관·사람·전화·업체·문서번호). 실제 공문·매뉴얼 내용은 넣지 않았습니다.
- 휴대용 묶음 구성: CPython 3.12.10(PSF), pypdf(BSD), pypdfium2(Apache-2.0/BSD, PDFium BSD), openpyxl(MIT), et_xmlfile(MIT), olefile(BSD), Pillow(MIT-CMU), winocr·winrt(MIT). 재배포 제한 구성요소 없음. 한글 파일은 자체 추출기(olefile+zlib)로 읽습니다(AGPL인 pyhwp는 쓰지 않음).
