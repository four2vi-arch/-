### 3. LLM 연결 설정

- 연결 위치: 「어르신 직접 입력」을 연 뒤 오른쪽 아래 「직원」을 2초 누르고 「고급 설정(인쇄 확인 창 없애기 · AI 주소 정리)」을 펼친 곳의 「AI 주소 정리 연결(선택)」 칸입니다. 주소·모델 이름을 넣고, 키 입력 위치는 「키(필요한 곳만)」 칸입니다.
- 방식·교체: OpenAI 호환 `/v1/chat/completions`이며 OpenAI 꼴·Ollama 꼴 답을 모두 읽습니다. 모델은 「모델 이름」만 고쳐 바꿉니다.
- AI가 하는 일: 규칙만으로 확정하지 못한 어르신 주소 문장 하나를 주소 조각으로 정리합니다(지시문 「우편번호는 절대 만들지 마라」). 조각은 고시 자료로 다시 찾아 판정이 나아질 때만 쓰고, 25초 안에 답이 없거나 고시 자료에 없으면 버립니다.
- AI 없이 되는 범위: AI는 어르신 화면에서만 부릅니다. 주소록 판정·양식 변환·라벨·사진 읽기·QR 메모는 AI 없이 동작하고, 모델을 바꾸거나 끊어도 주소록 판정 결과는 같습니다.

**연결 순서(같은 PC의 Ollama 예, 공통기반 지원(예정) 모델 목록의 엑사원·젬마 계열)**

1) 모델 받기: `ollama pull exaone3.5:7.8b`, `ollama pull gemma3:4b`
2) 위 칸에 주소 `http://127.0.0.1:11434/v1/chat/completions`, 모델 이름 `exaone3.5:7.8b` 또는 `gemma3:4b`를 넣고 키는 비웁니다.
3) 「AI 연결 시험」을 눌러 「연결됨 · exaone3.5:7.8b · ○.○초 · 뽑은 주소: …」처럼 나오면 「저장」을 누릅니다(실패하면 「연결되지 않았어요.」 뒤에 원인이 나옴).
4) 「연결이 거부됐어요」가 나오면(파일로 연 화면은 출처가 `null`일 수 있음) `setx OLLAMA_ORIGINS "*"` 뒤 Ollama를 다시 시작합니다. `*`는 다른 웹 페이지에도 열리므로 시연 뒤 지웁니다.

- 원격 모델(공통기반 등): 이 판은 이 PC(127.0.0.1·localhost) 주소만 받습니다. OpenAI 호환 원격 주소를 쓰려면 `소스/template.html` CSP와 `소스/src/kiosk.js`의 `isLocalUrl()`을 고쳐 `python build.py`로 다시 만듭니다(SHA-256 바뀜, 그 서버의 CORS 허용과 개인정보 검토 필요, 자세한 방법은 README).
- 확인한 범위: AI 연결은 OpenAI 호환 시험용 모의 서버로만 확인했습니다. 실제 모델(엑사원·젬마 등)로 물어물어를 돌린 기록은 아직 없습니다.

### 5. 기능 사용 순서

발송(①②)과 민원실 접수(③)의 업무 순서입니다. 기대 결과와 같으면 정상입니다.

**흐름 ① 주소록 → 우편번호(판정과 근거)**

1) `예시_주소록_공공기관(모의데이터).xlsx`를 「주소록 넣기」에 끌어 놓고 「우편번호 검색」을 누릅니다. 기대 결과: 주소 열이 자동으로 잡히고 행마다 정확·유사·실패와 근거가 붙습니다. 시·군·구를 알 수 없는 주소는 확정하지 않고 실패나 유사(추정 표시)로 남깁니다. 이름·전화·번지·동/호수는 가려집니다(「보기」로 10초).
2) 「점검표(유사·실패)」로 확인할 행만 받고, 내려받기 칸에서 「원본 + 우편번호」 → 「내려받기」를 누릅니다. 기대 결과: 원본은 그대로 두고 `…_우편번호.xlsx` 새 파일이 나옵니다. 양식을 고르지 않으면 「양식1 · 등기용」으로 `…_양식1(등기용).xlsx`가 나오고 유사 행 비고에 「확인 필요」가 찍힙니다.

**흐름 ② 발송 명단 1,000건 → 기관 양식·라벨**

3) 「라벨 인쇄」에서 A4 라벨 9종 중 하나를 골라 미리 봅니다. 우체국 접수 양식은 내려받기 칸에서 「우체국쇼핑 여러곳배송」(300건씩 나눔)이나 「계약소포 파일등록」(5,000건씩 나눔)을 골라 만듭니다(우체국쇼핑은 「보내는 분」을 먼저 채움).

### 6. 알려진 제약 사항

- 판정 범위: 구간 자료라 건물 실재·수취인 거주는 확인하지 않습니다. 모의 명단 1,000건은 고시 자료 안의 주소(344건 표기 변형)라 자료에 없는 주소의 정확도를 뜻하지 않습니다.
- 자료 기준일: 내장 DB는 2026-09-08 기준입니다. 매월 바뀌는 고시는 「DB 최신화」에서 PC마다 파일로 바꿉니다(인터넷 없이 가능). 내장 DB를 다시 빌드하는 도구는 소스에 없습니다.
- 밖으로 나가는 연결: ① 「DB 최신화」의 연결 확인·고시 파일 받기(주소록은 보내지 않음) ② 「말로 하기」는 브라우저 음성 인식이라 말소리가 브라우저 제작사 서버로 갈 수 있습니다(화면 안내 문구에 빠져 있어 이 문서로 알림, 운영 전 개인정보 검토 필요) ③ AI를 연결하면 어르신 주소 문장 하나가 이 PC 안의 모델로 갑니다.
- 개인정보·키: 처리 이력에 주소·이름은 남지 않고, 어르신 화면은 기본 2분(받는 곳 저장 뒤 5분) 동안 손대지 않으면 묻고 30초 뒤 지웁니다. 키는 브라우저 저장소에 평문으로 남으므로 공용 PC에는 넣지 않습니다.
- 원본 보호: 넣은 파일은 읽기만 하고 결과는 새 파일로 냅니다. 여러 시트 파일은 한 번에 한 시트만 처리하고, 「원본 + 우편번호」 파일에는 그 시트만 담깁니다.
- 실기 확인 전: 실제 휴대폰 사진 읽기, 실제 모델 2종 구동, 태블릿 USB(OTG)·제조사 앱 보내기(가짜 장치 시험만). 안드로이드에서 「내 파일」로 파일을 열면(content://) 크롬이 마이크·카메라를 막아 말로 하기·사진 읽기가 안 됨(크로미움 소스로 확인, 이 기기 안 주소 localhost로 열면 됨)
- 오픈소스: 재배포가 제한되는 구성요소는 없습니다. xlsx-js-style 1.2.0(Apache-2.0, 두 곳 수정)·fflate(MIT)·qrcode-generator 1.4.4(MIT)·Tesseract.js 5.1.1·tesseract.js-core 5.1.1·한국어 tessdata_best(Apache-2.0). 전문은 「파일 정보」와 `소스/LICENSES/`에, 수정 고지는 `소스/LICENSES/`에 있습니다.
- 소스: `소스/`에서 `python build.py`를 실행하면 출품본과 SHA-256이 같은 파일이 만들어집니다. 현장 배포본(난독화)에서 되살린 소스라 함수 안 지역 변수는 자동 이름입니다. 참고 개발물: 【사용자 확인: 없으면 「없음」, 있으면 이름과 출처】

### 7. 개발 경위 요약(1쪽 이내)

**필요성(문제)** 고지서·안내문·소포를 보내는 기관은 주소록에 우편번호를 한 건씩 찾아 넣고 접수 양식에 다시 옮겨 적습니다. 오탈자·옛 행정구역명·지번 주소는 고쳐 가며 다시 찾아야 하고, 외부 서비스로 한꺼번에 돌리면 주소 자료가 기관 밖으로 나갈 수 있습니다. 민원실에서는 주소 쓰기를 어려워하는 어르신의 대필 요청이 잦습니다. 【사용자 확인: 민원실 대필·안내 요청 집계(’26.10.13.~23.) 건수. 집계가 없으면 이 표시를 지움】

**창의성(접근)** 「AI는 정리하고, 공공 기준이 확정한다」. AI는 말에서 주소 조각만 정리하고, 우편번호는 우정사업본부 우편번호 고시 자료(구간 565,732건)로만 확정하며, 판정 근거를 함께 보여 사람이 볼 곳만 남깁니다. AI 답은 고시 자료로 다시 확인해 나아질 때만 쓰고, AI가 거든 결과는 화면에 밝힙니다. 번호가 하나로 정해지지 않으면 어르신 화면은 숫자를 보이지 않고 창구로 넘기고, 주소록은 가장 좁은 구간 번호에 「유사 · 창구 확인」을 붙여 점검표로 모읍니다(AI 신뢰성 확보).

**활용성(효과)** 주소록을 파일째 넣어 행마다 판정·근거를 붙이고, 확인할 행만 점검표로 모으며, 기관 양식·A4 라벨·우체국 접수 양식으로 바로 냅니다. 모의 발송 명단 1,000건을 넣으면 기관 양식 1,000행이 채워지며, 서버·설치·계정·사용료가 들지 않습니다. 【사용자 확인: 같은 주소록 100건을 손으로 채운 시간과 이 도구로 채운 시간(직원 실측). 재지 않았으면 이 표시를 지움】

**완성도(구현)** 설치·서버 없는 HTML 파일 1개, 내부망 구동, 「원본 확인됨」 무결성 자체 확인, 개인정보 기본 보호(화면 가림·처리 이력·자동 지우기), 소스로 같은 파일 재현(SHA-256 일치), 자동 시험 통과(어르신 시나리오 22항목 등, ’26.10.18.)

**확산가능성(확산)** 기관은 자기 양식 파일만 넣으면 그 열 구성대로 변환되고, 고시 변경은 파일 교체로, 모델은 「모델 이름」만 바꿔 옮깁니다. 판정 엔진은 화면과 떨어진 모듈이라 정보화사업으로 옮기기 쉽고, 배포는 파일 하나입니다.
