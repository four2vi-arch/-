# 물어물어(우편번호 자동검색기): 어르신의 말도 엑셀 명단도 되묻고 고시에 물어 우편번호로 찾아가는 AI 주소 도우미

> 2026년 공공 AI 대전환 챌린지 · 세션1(자유주제) · 정읍우체국 영업과 이희재 · v1.4(2026-10-09)

고지서·안내문을 보내는 기관은 주소록마다 우편번호를 한 건씩 찾아 양식에 옮겨 적고, 민원실에서는 주소 쓰기가 어려운 어르신의 대필 요청이 잦습니다. 이 도구는 두 일을 한 파일로 해결합니다. 주소록을 넣으면 우편번호를 일괄로 찾아 근거와 함께 붙이고 기관 양식으로 바꾸며, 민원실 화면에서는 어르신이 말하거나 적은 주소를 되물어 정리합니다. 생성형 AI는 규칙이 풀지 못한 말을 주소 조각으로 정리하는 데만 쓰이고, **우편번호는 언제나 우정사업본부 우편번호 고시 자료로만 확정**하므로 지어낸 번호가 나올 수 없습니다. 모든 처리는 이 PC의 브라우저 안에서만 이루어집니다.

## 접속 주소

서버·설치·계정이 없습니다. 이 저장소의 `실행물/우편번호_자동검색기_v1.4_출품본.html` 한 파일을 내려받아 엣지 또는 크롬으로 열면 됩니다(인터넷 없는 내부망·오프라인 가능). 화면 위에 「우편번호 DB 기준일 2026-09-08 · 내장 (구간 565,732건)」, 맨 아래에 「원본 확인됨」이 보이면 준비된 것입니다.

## 주요 기능

- **주소록 일괄 판정**: 엑셀·CSV·한셀 주소록의 주소 열을 자동 인식하고, 행마다 정확·유사·실패 판정과 근거(「도로명 보정(세종데로→세종대로)」 등)를 붙입니다. 고시 자료에서 무작위로 뽑아 표기 변형 344건을 섞은 주소 1,007건 중 1,000건 정확(99.3%, 유사 4·이웃 구간 3), 1,000건 판정 0.06초(2026-10-05, 크로미움 141 자체 측정).
- **기관 양식으로 변환**: 기관 양식 파일의 제목 줄을 읽어 그 열 구성대로 채워 내려받습니다(사용자 지정 양식). 우체국 접수 양식 2종(우체국쇼핑 여러곳배송·계약소포 파일등록)은 사용자 양식의 예시로 들어 있습니다. A4 라벨 9종 인쇄, 유사·실패만 모은 점검표(추천 후보 포함).
- **어르신 직접 입력**: 큰 글씨 대화 화면에서 빠진 부분(지역·건물·번지·동호수)만 되묻고, 소리로 읽어 주며, 접수 메모(QR)를 뽑아 창구 화면의 주소록으로 넘깁니다. 민원실 기기는 파일 주소 끝에 `#kiosk`를 붙여 열면 처음부터 이 화면으로 시작합니다.
- **AI는 정리, 확정은 고시 자료**: 로컬 모델이 정리한 주소도 우편번호 DB로 다시 찾아 판정이 나아질 때만 채택합니다. AI에는 주소 문장 하나만 보내고 이름·전화는 보내지 않습니다.
- **개인정보 보호**: 주소록은 브라우저 안에서만 처리하고 서버로 보내지 않습니다. 화면 가림, 건수만 남는 처리 이력, 「끝내고 지우기」, 자리 비움 자동 지우기. 넣은 파일은 읽기만 하고 결과는 새 파일로 냅니다.
- **DB 최신화**: 매월 바뀌는 우편번호 고시는 국가법령정보센터 별표 5 또는 인터넷우체국 범위주소 파일을 넣어 교체합니다(인터넷 없이 가능).

## 실행·작동 방법

1. `실행물/`의 HTML을 엣지 또는 크롬으로 엽니다. 처음 한 번 「개인정보 취급 안내」에서 「알겠습니다」를 누릅니다.
2. **흐름 ① 주소록 → 우편번호**: `모의데이터/예시_주소록_공공기관(모의데이터).xlsx`를 「주소록 넣기」에 끌어 놓고 「우편번호 검색」을 누릅니다. 「점검표(유사·실패)」로 확인할 행만 받고, 「내려받기」로 `…_우편번호.xlsx`를 만듭니다.
3. **흐름 ② 발송 명단 1,000건 → 기관 양식·라벨**: `예시_발송명단_DB추출(모의데이터).xlsx`를 넣고 검색한 뒤, 「사용자 지정 양식」 → 「양식 파일에서 불러오기」로 `예시_기관발송양식(모의데이터).xlsx`를 고르면 그 열 구성대로 채워집니다. 「라벨 인쇄」에서 규격을 골라 미리 봅니다.
4. **흐름 ③ 민원실 어르신 직접 입력**: 「어르신 직접 입력」 → 「시작하기」 → `모의데이터/어르신_입력_시연문장.txt`의 문장을 적고 「다 적었어요」 → 확인 화면 → 이름·전화 → 「접수 메모」 → 「직원 확인: 접수 화면으로 넘기기」로 주소록에 들어옵니다.
5. 「예시로 해 보기」를 누르면 모의 주문서 10건으로 흐름 ①②를 바로 체험할 수 있습니다.

## AI 연결(선택, 모델 비종속)

이 PC에서 돌리는 로컬 모델만 OpenAI 호환 주소로 연결합니다. 접속 허용 목록에 따라 외부 주소는 막힙니다. 예) Ollama

```
ollama pull exaone3.5:7.8b
ollama pull gemma3:4b
```

어르신 화면 오른쪽 아래 「직원」 단추를 2초 누름 → 주소 `http://127.0.0.1:11434/v1/chat/completions`, 모델 이름 `exaone3.5:7.8b` 또는 `gemma3:4b` → 「AI 연결 시험」 → 「저장」. 모델 이름만 바꾸면 다른 모델로 바뀝니다. 파일로 연 화면의 출처가 거부되면 `OLLAMA_ORIGINS`에 `*` 또는 `file://*`를 넣고 Ollama를 다시 시작합니다. 연결 시험이 실패하면 원인(시간 초과·모델 이름·키·허용 출처)이 화면에 표시됩니다.
