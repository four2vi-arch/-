# 물어물어(우편번호 자동검색기) v1.5 · 소스

## 구성
| 경로 | 내용 |
|---|---|
| `src/ui.js` | 주소록 읽기·열 자동 인식·검색·결과 표·양식 변환(원본+우편번호, 우체국쇼핑 복수배송지, 계약소포, 사용자 양식)·라벨·점검표·개인정보 가림·처리 이력·DB 최신화 |
| `src/engine.js` | 주소 판정 엔진 `ZipEngine` · `lookup`(주소→우편번호·등급·근거), `search`(주소 찾기 목록), `parseRegion`, 건물명·행정동 보정 |
| `src/dbbuild.js` | 우편번호 고시 별표 5·인터넷우체국 범위주소 DB를 엔진용 구조로 바꾸는 빌더(「DB 교체」에서 사용) |
| `src/kiosk.js` | 어르신 직접 입력(큰 글씨 대화 화면)·AI 보조(선택, 로컬 모델)·감열 인쇄·QR 접수 메모·창구 QR 읽기·예시 체험 |
| `vendor/` | fflate(MIT), xlsx-js-style(Apache-2.0), qrcode-generator(MIT) · 원본 그대로, 전문은 `LICENSES/` |
| `data/` | 내장 우편번호 DB(gzip+base64) · 공개 자료 기반, 기준일은 화면에 표시 |
| `template.html` | 화면 틀(HTML·CSS)과 자리표시자 |
| `build.py` | 파일을 모아 단일 HTML(`dist/`)을 만들고 무결성 지문과 CSP를 다시 계산 |
| `tools/모의주소_추출.js` | 내장 DB에서 도로명·지번 주소를 임의로 뽑아 모의 발송 명단과 정답 파일(CSV)을 만드는 도구(`node tools/모의주소_추출.js`, 출품본에는 들어가지 않음) |

함수 안의 지역 변수는 짧은 이름(a, b, row, i …)을 자동으로 붙였습니다. 배포본과 동작이 같음을 회귀 시험으로 확인했습니다.
