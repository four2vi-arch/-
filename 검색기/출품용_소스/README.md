# 물어물어(우편번호 자동검색기) v1.11 · 소스

이 폴더로 `실행물/`의 출품본과 바이트 단위로 같은 HTML을 다시 만들 수 있습니다. 파이썬 표준 라이브러리만 쓰므로 따로 설치할 부품이 없습니다.

## 만들기
```
python build.py
```
`dist/우편번호_자동검색기_v1.11_출품본.html`이 만들어집니다. 함께 낸 `실행물/` 출품본과 바이트 단위로 같습니다(SHA-256 `a6d7acdcf8b15e40f1626946827941e3b49b4505c88411bad0bac8ab48b73e48`, 2026-10-26 v1.11). 줄바꿈을 LF로 고정해 윈도에서 만들어도 같은 값이 나오게 했습니다.

`build.py`가 하는 일은 셋입니다.
1. `template.html`의 자리표시자에 `data/`·`vendor/`·`src/` 파일을 끼워 넣습니다(한국어 학습자료는 base64로 바꾸고, `camera.js`에는 글자 읽기 블록의 SHA-256을 적어 넣음).
2. 핵심 코드 9개를 이어 SHA-256 지문을 계산해 무결성 검증기와 「파일 정보」에 적습니다. 화면 맨 아래 「원본 확인됨」이 이 검증 결과입니다.
3. 실행되는 inline script의 SHA-256으로 CSP(`script-src`)를 다시 만듭니다. `connect-src`(접속 허용 목록)는 `template.html`에 적힌 그대로 둡니다.

## AI 관련 코드 위치
생성형 AI(언어 모델)는 어르신 화면에서만 쓰고, 주소록 판정(`ui.js`·`engine.js`)에는 쓰지 않습니다. 모두 `src/kiosk.js`에 있습니다.

| 이름 | 하는 일 |
|---|---|
| `SYS` | 지시문. 주소 조각 JSON 하나로만 답하고, 우편번호는 만들지 말고, 이름·전화는 넣지 말라고 함 |
| `isLocalUrl()`·`aiCfg()` | 주소가 `http(s)://127.0.0.1` 또는 `localhost`일 때만 설정을 씀 |
| `aiExtractRaw()` | OpenAI 호환 요청(지시문과 문장 하나, `temperature: 0`, `response_format: json_object`, 25초 제한, 키가 있으면 Bearer) |
| `parseJsonLoose()` | 답에서 JSON 하나만 꺼냄(`<think>…</think>`·코드 표시(```) 제거). OpenAI 꼴·Ollama 꼴 답을 모두 읽음 |
| `aiAssist()` | AI가 준 조각으로 엔진 `lookup`을 다시 돌림. 고시 자료에서 못 찾으면 버림 |
| `resolve()` | 규칙으로 먼저 찾고, AI 결과는 판정이 나아질 때만 채택. 「기다리지 않고 진행」 단추 |
| `confirmAddr()`·`isGuess()` | AI 도움 표시. 번호가 하나로 정해지지 않으면 숫자를 보이지 않고 창구 확인 |
| `handOff()` | 창구로 넘기는 파일 비고에 「창구 확인 필요(사유)」 |
| `aiTest()` | 직원 설정 「AI 연결 시험」 |

모델을 바꿀 때는 코드를 고치지 않고 직원 설정의 「모델 이름」만 바꿉니다. 이 PC 밖의 OpenAI 호환 주소(공통기반 등)를 쓰려면 ① `template.html` 5행 CSP의 `connect-src`에 그 주소를 더하고 ② `isLocalUrl()`이 그 주소도 받도록 고친 뒤 ③ `python build.py`로 다시 만듭니다. 다시 만든 파일은 SHA-256이 바뀝니다. 그 서버의 CORS(파일로 연 화면은 출처 `null`)와 개인정보 검토는 따로 확인해야 합니다.

## 시험
판마다 헤드리스 크로미움으로 출품본을 자동 구동해 확인했습니다. 프린터·카메라·AI 서버·음성 인식은 가짜(모의)로 대신했습니다. v1.11 기준 통과 항목은 어르신 시나리오 22, 양식 13, 라벨 13, 블루투스 29, USB 25, 태블릿 인쇄·말로 하기·직원 설정 124(`v111_test`)입니다(2026-10-26). 사진 읽기 11·20은 v1.10(10.18.)에서 통과했고 v1.11에서 사진 읽기 코드는 바꾸지 않았습니다. 시험 도구와 검토 기록은 개발용 저장소에 있고 이 저장소에는 넣지 않았습니다. 아래 변경 기록에 나오는 시험 이름(`elder_test` 등)은 그 도구 이름입니다.

태블릿(갤럭시 탭 S7 FE)과 4인치 감열 라벨프린터의 블루투스 인쇄는 개발자가 실기로 시험하며 고쳤습니다(10.23.~26.). USB(OTG)·제조사 앱 보내기는 가짜 장치 시험만 했습니다. 실제 모델(엑사원·젬마 등) 연결은 아직 확인하지 않았습니다.

## 이름 복원에 대해
현장에 배포한 판은 난독화한 HTML 파일이었기 때문에, 출품을 위해 그 파일에서 소스를 되살렸습니다. `실행물/`의 출품본은 이 폴더 소스로 만든 것입니다. 함수·상수 이름(약 200개)은 역할에 맞게 다시 붙였고, 함수 안의 지역 변수는 짧은 이름(a, b, row, i …)을 자동으로 붙였습니다. 배포본과 동작이 같음을 회귀 시험으로 확인했습니다.
