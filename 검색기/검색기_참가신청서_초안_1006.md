## 2. 개요 및 주요 기능(핵심 요약)

### 10.12. 사전 송부본(공백 제외 약 900자)

필요성: 고지서·안내문을 보내는 모든 기관은 주소록마다 우편번호를 한 건씩 찾아 양식에 옮겨 적고, 오탈자·옛 행정구역명·지번 주소는 고쳐 가며 다시 찾는다. 외부 서비스에 올리면 주소 자료가 기관 밖으로 나가고, 민원실에서는 주소 쓰기가 어려운 어르신의 대필 요청이 잦다.
창의성: 「AI는 정리하고, 공공 기준이 확정한다」. 주소록 일괄 판정은 규칙과 고시 자료로, 민원실의 자유 문장(말·글)은 규칙이 먼저 정리하고 규칙이 풀지 못한 것만 생성형 AI가 주소 조각으로 정리한다. 우편번호는 우정사업본부 우편번호 고시 별표(국가법령정보센터 공개, 565,732구간, ’26.9.8. 기준)로만 확정하므로 자료에 없는 번호는 나오지 않고, 확정하지 못한 주소는 지어내지 않고 근거와 함께 사람에게 넘긴다. 기존 주소 API·주소 정제 서비스와 달리 인터넷 연결·자료 전송 없이 내부망 PC에서 돈다.
활용성: 엑셀·CSV 주소록의 주소 열을 자동 인식해 정확·유사·실패 판정과 근거를 붙이고, 기관 양식 파일의 제목 줄을 읽어 그 열 구성대로 변환하며 A4 라벨 9종으로 인쇄한다. 고시 자료에서 무작위로 뽑아 표기 변형 344건을 섞은 주소 1,007건 중 1,000건 정확(99.3%, 나머지 유사 4·이웃 구간 3), 1,000건 일괄 판정 0.06초(’26.10.5., 크로미움 141 자체 측정). 설치·서버·외부 정제 비용이 없다. 민원실에서는 어르신이 직접 입력한 주소가 접수 메모(QR)로 인쇄되어 담당자 화면의 주소록에 들어간다(PC에 저장되지 않음).
완성도: 설치·서버·계정 없는 HTML 파일 1개, 첫 열기 약 1초, 소스로 같은 파일을 다시 만들어 SHA-256 일치를 확인했다. 화면 가림·처리 이력·끝내고 지우기·자리 비움 자동 지움이 기본이고, 넣은 파일은 읽기만 하며 결과는 새 파일로 낸다. 소스·구동안내서·모의데이터를 함께 내며, 참가자가 공개 자료와 가상 명단만으로 생성형 AI의 지원을 받아 직접 개발했다(’26.9.19. v1.0부터).
확산가능성: 기관은 자기 양식 파일만 넣으면 그 열 구성대로 변환되고, 매월 바뀌는 고시는 자료 파일 교체로, 모델은 API 주소·모델 이름으로 바꿔 특정 모델에 종속되지 않는다. 고지서·안내문을 보내는 모든 기관과 민원 창구에 그대로 재사용하며, 범정부 공동활용 때는 파일 하나를 배포한다.
