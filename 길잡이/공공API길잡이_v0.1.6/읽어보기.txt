공공API 길잡이 v0.1.6 (시제품) — 말 한 줄로 공공데이터 도구 만들기

■ 준비물
  - 인터넷이 되는 PC + 파이썬 3.8 이상(없으면 python.org 에서 설치, 또는 WinPython 휴대용)
  - 공공데이터포털(data.go.kr) 인증키 — 마이페이지 > 데이터 활용 > Open API > 인증키 발급현황
  - (선택) 주소정보누리집 도로명주소 검색 API 승인키 — 주소정보누리집 개발자센터에서 신청
  - (선택) AI: Ollama 등 OpenAI 호환 로컬 모델 (예: exaone3.5:7.8b, gemma3:4b)

■ 첫 시험 순서
  1. 공공데이터포털에서 아래 4종을 「활용신청」합니다(대부분 자동승인, 승인 직후 1시간쯤 지나야 키가 먹는 경우가 있음).
     - 한국천문연구원_특일 정보
     - 기상청_단기예보 ((구)_동네예보) 조회서비스
     - 한국환경공단_에어코리아_대기오염정보
     - 국세청_사업자등록정보 진위확인 및 상태조회 서비스
  2. 실행.bat 을 두 번 누르면 브라우저에 길잡이가 열립니다.
  3. 오른쪽 위 「설정」 → 인증키(Decoding·Encoding 아무거나) 저장. AI를 쓰면 주소·모델 이름도 넣습니다.
  4. 예시 단추를 눌러 API를 고르고 「실제로 불러 보기」 → 표가 나오면 성공입니다.
     오류가 나면 화면의 안내 문장(예: 등록되지 않은 인증키, 활용신청 확인)을 그대로 알려 주세요.
  5. 「도구 만들기」를 누르면 만든도구 폴더에 도구.py·설정.ini·실행.bat·읽어보기.txt 가 생깁니다.
     만든 도구는 설정.ini 에 키를 넣고 실행.bat 을 누르면 결과를 CSV(엑셀)로 저장합니다.

■ 보안
  - 이 PC(127.0.0.1)에서만 열리고, 다른 사이트가 몰래 부를 수 없도록 화면마다 비밀 표식을 확인합니다.
  - 인증키는 이 폴더 config.json 에만 저장되고, AI에는 사용자의 문장과 공개 API 명세만 보냅니다.
  - 만든 도구 안에는 인증키를 넣지 않습니다(설정.ini 에만). 남에게 줄 때는 설정.ini 의 키를 지우세요.

■ v0.1.6에서 바뀐 점 — 실제 키로 7종 모두 호출 확인
  - 등기 2종(배달상태 일괄조회·배송 경로 조회)을 「호출 확인됨」으로 표시
  - 제공기관이 빈 값을 글자 「null」로 보내는 경우 빈칸으로 표시(예: 아직 배달 전인 등기의 배달일시)

■ v0.1.5에서 바뀐 점
  - 「목록에서 직접 고르기」 상자 추가: 검색하지 않고 7종 중 원하는 API를 바로 선택
  - 예시 단추에 「보낸 등기 배달됐는지 확인」 추가
  - 검색 후보를 너무 많이 숨기던 문제 조정(관련 후보는 함께 표시, 한 낱말만 스친 후보만 숨김)

■ v0.1.4에서 바뀐 점
  - 키가 빠졌을 때 어느 키인지 정확히 안내(공공데이터포털 인증키 / 주소정보누리집 승인키)
  - 낱말 검색에서 「확인·궁금·조회」 같은 뜻 없는 말은 빼고, 엉뚱한 후보(예: 폐업 확인에 날씨)는 숨김
  - 실키로 확인된 「사업자등록 상태조회」를 「호출 확인됨」으로 표시(확인 완료 5종)

■ v0.1.3에서 바뀐 점
  - 우정사업본부 API 2종 추가(이미 활용신청된 「국내우편물 종적 조회 서비스」 사용, 같은 인증키)
    · 등기우편물 배달상태 일괄조회: 등기번호 여러 개 → 우편물 종류·취급구분·배달상태·배달일시 한 표
    · 등기우편물 배송 경로(종적) 조회: 등기번호 하나 → 접수~배달 날짜·시각·위치·처리현황
  - 여러 건 처리: 쉼표·줄바꿈으로 여러 개 입력, 또는 번호가 든 txt·csv 파일 경로 입력(만든 도구)
    · 길잡이 화면의 「실제로 불러 보기」는 앞 10건만 시험, 만든 도구는 전체 처리
    · 사업자등록번호는 100개씩 나눠 자동 조회, 자릿수가 틀린 번호는 빼고 알려 줌
  - 결과를 읽기 쉽게: 모든 항목 우리말, 핵심 항목만 표시, 코드 풀이
    · 단기예보: 시간별 한 줄(기온·하늘·강수 형태·강수확률·습도·풍속), 하늘·강수 코드를 말로
    · 대기오염: 등급 1~4 → 좋음·보통·나쁨·매우나쁨
    · 날짜에 요일 표시(예: 2026-10-05 (월)), 사업자번호 하이픈 표시
  - 400·411·413 오류도 우리말 안내

■ v0.1.2에서 바뀐 점
  - 만든 도구의 실행.bat 을 한글 윈도 기본 인코딩(CP949)·CRLF·goto 방식으로 저장
    (UTF-8 배치파일에서 한글 파일명이 깨져 「명령이 아닙니다」 오류가 나는 문제 예방)

■ v0.1.1에서 바뀐 점
  - 실키로 확인된 「단기예보」「도로명주소 검색」을 「호출 확인됨」으로 표시
  - 401·403 오류를 우리말로 안내(키 인식 실패 / 활용신청·승인 반영 전)
  - 403이 나면 인증키 이름(serviceKey ↔ ServiceKey)을 바꿔 한 번 더 자동 시도
  - 만든 도구도 같은 우리말 오류 안내 사용
  - 설정(config.json)은 그대로 쓰면 됩니다. 새 폴더에 옮길 때는 config.json 도 함께 복사하세요.

■ 시제품 범위와 한계
  - 도구까지 만들 수 있는 API는 5종(특일·단기예보·대기오염·사업자 상태·도로명주소)이며, 「명세 확인 대기」 표시는
    실제 키로 호출해 확인하기 전이라는 뜻입니다. 확인되면 「호출 확인됨」으로 바꿉니다.
  - 다음 판에서 API 30~50종으로 넓히고, 공공데이터포털 목록 전체에서 찾는 기능을 붙입니다.
