# 역할별 모의 사용 검토와 개선(2026-10-18)

요청: ① 70대 어르신이 물어물어를 직접 쓸 때의 문제, ② 1년 근무한 수습사무관이 돌다리로 업무를 넘길 때 당황할 점, ③ 신규 수습사무관이 그 결과물만 받고 정말 인수인계가 되는지. 문제를 찾아 고친 뒤, **고친 것이 새 오류를 만들지 않았는지 다시 검토**해 한 번 더 고쳤다.

진행: 1차 역할별 모의 사용(셋) → 수정(물어물어 v1.10, 돌다리 v3.7) → 2차 독립 검토(고친 뒤 생긴 결함, 둘) → 수정(돌다리 v3.7.1, 물어물어 v1.10 보완) → 회귀 시험 전부. 자료는 모두 가상(이름·전화 010-0000-…, 063-000-…, 가상 기관)이다.

| 휴대폰에서 번호를 찾는 사이 다 지워짐 | 자리 비움 2분 | 받는 곳 저장 뒤 5분, 지우기 전 30초 알림(아무 곳이나 누르면 계속) |
| 접수 번호가 지울 때마다 건너뜀 | 번호를 화면마다 받음 | 첫 받는 곳을 저장할 때 하루 차례 번호(001) |

### 2차 검토에서 찾은 것(고친 뒤 생긴 결함)과 고친 것

|---|---|---|

| 중 | 「직원 도움」 → 「다시 적기」 뒤 빈 받는 곳이 남아 빈 스티커 | 「창구에서 할게요」를 눌렀을 때만 메모로 남김 |
| 중 | 「아드님」→「아드」, 「김씨」→「김」으로 잘라 저장, 「할머니」는 확인 표시 없음 | 성함이 아닌 말은 그대로 두고 창구 확인(가족·호칭 말 목록 넓힘) |

남은 것(이번에 손대지 않음): 번지를 적었는데 범위 밖이면 번지를 한 번 더 묻는 것(전부터 있던 동작), 우편번호가 하나뿐인 리에서도 번지를 묻는 것.

시험: `검색기/시험/elder_test.js` 22항목(위 시나리오 전부) 통과. 기존 form 13·label 13·ble 29·usb 25·cam 11·cam_extra 20 통과. 오류(pageerror) 0, 노트북 1366×768·태블릿 800×1280 모두.

## 2. 1년 근무 수습사무관(넘기는 쪽) × 돌다리

가상 폴더 `김수습_업무자료(1년)`: 월별 폴더(2025.11 …)·다운로드·바탕화면이 섞이고, 같은 보고서의 _v1·_최종·(1)·사본, 멘토 면담·교육과제, 계정 메모(비밀번호), 「매월 5일까지」 같은 줄, 회신 대기 메모.

| 당황한 곳 | 고친 것(v3.7) |
|---|---|
| 업무가 「2025.11」「다운로드」로 나뉨 | 날짜·임시 폴더는 업무로 보지 않음(반이 넘으면 키워드로 나눔, 「키워드로 나누기」 단추) |
| 같은 보고서가 판마다 따로 항목 | 사본(지문 같음)·수정본은 최신 하나, 나머지는 붙임에 「이전 판·사본」 |
| 멘토 면담·병가 신청이 인계서에 | 개인 문서는 현안으로 올리지 않고 제목도 싣지 않음 |
| 계정 메모의 비밀번호가 발췌에 그대로 | 값만 ●●●, 「계정 정보 있음」 표시 |
| 다 「진행」으로만 나옴 | 「결론 못 냄」「회신 대기」는 미결 제안, 「후임자가 ~할 것」은 할 일 |
| 매월 하는 일이 안 나옴 | 「매월 ○일까지」「매주 ○요일」, 옛 인수인계서·매뉴얼의 「○월 ○일까지」를 반복 업무로 |
| 이미 넘긴 업무를 하나씩 빼야 함 | 업무 단위 「이미 넘긴 업무」 → 한꺼번에 빼고 1-가에 「인계 완료」 |
