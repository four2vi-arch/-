# 물어물어 v1.7 — 저가 안드로이드 태블릿 + 무선 라벨프린터 검토 (2026-10-16)

## 1. 요구
- 아이패드 제외, **저가 안드로이드 태블릿**, **낮은 안드로이드 버전**에서도 동작
- **블루투스 또는 와이파이 다이렉트** 무선 연결 (컴퓨터는 설치 공간·이동성 때문에 제외)
- 어르신이 휴대폰 문자 화면을 찍으면 읽어서 주소를 찾고, 기표지에 붙일 스티커를 뽑는 흐름 유지

## 2. 결론(권고)
**안드로이드 태블릿(크롬) + 배터리 내장 휴대용 라벨프린터(BLE 지원)**, 앱이 스티커 그림을 만들어 BLE로 직접 보냅니다(v1.7에 구현). 와이파이 다이렉트는 웹앱에서 직접 쓸 수 없어 1순위로 권하지 않습니다.

| 연결 | 웹앱(크롬)에서 | 판단 |
|---|---|---|
| **블루투스 BLE** | Web Bluetooth로 직접 보냄(앱이 그림→TSPL/ESC/POS 변환) | **채택.** 프린터가 BLE여야 함 |
| 블루투스 클래식(SPP) 전용 | 웹에서 쓸 수 없음 | 불가(구매 때 걸러야 함) |
| 와이파이 다이렉트·와이파이 | 웹앱은 소켓·와이파이 다이렉트 접근 불가. 안드로이드 **인쇄 서비스** 플러그인을 거쳐야 함(Mopria 기본 서비스는 안드로이드 8부터, 와이파이 다이렉트 인쇄는 안드로이드 9부터·Mopria 인증 프린터) | 라벨프린터 대부분이 Mopria 인증이 아니고 라벨 크기 지정도 불확실 → 비권장 |
| 기존 방식(크롬 인쇄 창) | 인쇄 서비스에 프린터가 잡혀야 함 | 그대로 남겨 둠(컴퓨터·인쇄 서비스 있는 기기용) |

## 3. 안드로이드 버전 현실
- 크롬 139부터 **안드로이드 10 이상** 필요, 안드로이드 8·9는 크롬 138까지, 7.1 이하는 크롬 127부터 지원 중단(127부터 안드로이드 8 이상). 설치된 크롬은 계속 돌지만 **보안·기능 업데이트가 끊깁니다**.
- 앱이 쓰는 기능: 블루투스(Web Bluetooth, 제 기억으로 안드로이드 크롬 56 이상 — 확인 필요), 사진 읽기(wasm SIMD, 크롬 91 이상). 최신 업데이트가 되는 **안드로이드 10 이상 저가 태블릿**이면 모두 충족합니다. 블루투스 인쇄는 사진 읽기 없이도 되므로 구형 크롬이면 사진 단추만 숨겨지고(자동) 나머지는 동작합니다.
- 안드로이드 11 이하에서는 블루투스 검색에 「위치」를 켜야 할 수 있습니다(크롬 개발진 설명, 2016 W3C 메일). 설정 창 안내문에 넣었습니다.
- 메모리: 이 파일은 18MB이고, 컴퓨터에서 사진 읽기를 한 뒤 크롬 전체 메모리가 약 190MB 늘었습니다(컴퓨터 값). **RAM 3GB 이상**을 권합니다. 저가 태블릿의 글자 읽기 시간은 이 환경에서 잴 수 없었습니다(CPU 제한 시험이 글자 읽기 작업자에 걸리지 않음). 컴퓨터 기준 0.7~1.4초이므로 8~15배 느려도 10초대로 **추정**하지만 실기 측정이 필요합니다.

## 4. 프린터 선정 체크리스트
1. **BLE(Bluetooth 4.0 LE 이상)** 지원 — 클래식만이면 불가. 확인법: 태블릿에 nRF Connect(무료) 앱을 설치해 프린터가 검색되고 「쓰기 가능한 특성」이 보이면 BLE입니다.
2. **용지폭 ≥ 기표지 주소란 가로**(재서 확인). 80mm급(3인치)과 100~108mm급(4인치)이 있음.
3. 명령어: **TSPL** 또는 **ESC/POS 래스터**(앱 설정에서 선택). 한글은 그림으로 보내므로 프린터 한글 글꼴은 필요 없음.
4. 라벨 간격 인식(갭 센서), 배터리, 국내 A/S와 접착 라벨 용지 수급.
5. **구매 전 대여·시연 장비로 앱의 「시험 인쇄」를 먼저** 해 볼 것.

### 후보(확인된 범위만)
- **빅솔론 SPP-L410**(4인치 모바일 라벨프린터): 제조사 자료에 Bluetooth V4.1 Classic & LE, NFC 페어링, 유·무선 제어, 안드로이드·iOS·윈도 SDK(Chrome SDK 언급)가 있음. **BLE 서비스 번호·명령어 규격은 확인하지 못했습니다** → 제조사(국내)에 문의할 것. 국내 제조사라 A/S 이점.
- 빅솔론 SPP-L310(3인치): NFC 페어링, 안드로이드 SDK. **BLE 지원 여부 확인 못 함.**
- Phomemo PM-241-BT(4인치급): 203dpi, 라벨폭 25.4~117mm, 안드로이드는 전용 앱(Labelife)으로 연결. **명령어 규격 확인 못 함.**
- Brother QL-820NWB: 에어프린트·와이파이·블루투스 지원이나 아이패드 중심이고 용지폭 제한(제 기억 62mm, 확인 필요), 국내 판매·용지 수급 미확인.
→ 어느 것도 **이 앱과의 실제 호환은 확인하지 못했습니다.** 위 체크리스트로 1~2대를 시험 구매·대여해 확정하세요.

## 5. v1.7에서 만든 것
- **블루투스(BLE) 직접 인쇄**: 스티커 그림을 만들어 TSPL(비트맵) 또는 ESC/POS(래스터)로 BLE에 보냄. 설정 창(어르신 화면 직원 설정·직원 「라벨 인쇄」 공용)에서 명령·해상도(203/300dpi)·라벨 간격·회전·색 반전·보내는 크기·간격·추가 서비스 번호를 조정하고 「프린터 연결」「시험 인쇄」.
- 흔한 BLE 프린터 서비스 번호 11개를 미리 열어 두고(Web Bluetooth는 미리 적은 서비스만 열 수 있음), 쓰기 가능한 특성을 자동 선택. 프린터가 큰 조각을 막으면 100→20바이트로 자동 줄임.
- 태블릿 사진 읽기: **뒷 카메라 우선**, 카메라가 둘이면 「앞·뒤 카메라 바꾸기」, 첫 읽기에서 정확한 주소와 이름·전화가 나오면 두 번째 읽기 생략(컴퓨터 측정 약 0.7초 vs 1.2~1.4초).
- 블루투스를 못 쓰는 기기에서는 기존 인쇄 창 방식으로 자동 되돌아감.

## 6. 시험(가짜 BLE 프린터)
브라우저의 블루투스 인터페이스를 흉내 낸 가짜 프린터로 **보낸 바이트를 받아 스티커 그림을 되살려** 확인했습니다. 29개 항목 통과: 100×45·80×50 스티커 크기와 비트맵 크기(800×360 등), 3장 전송과 PRINT, 연결 1회, 큰 조각 거부 시 20바이트로 줄여 전송, 프린터 선택 취소 안내, ESC/POS 래스터 모양, 90도 회전·색 반전, 설정 창 연결·시험 인쇄·저장, 직원 라벨 창에서 주소록 전체 전송, 블루투스 없는 브라우저에서 기존 방식으로 대체, 오류 없음. 뒷 카메라 요청과 전환(20항목), 사진 읽기 전 과정·라벨·양식 회귀(각 통과).

### 아직 확인하지 못한 것(실기 시험 필요)
- **실제 프린터와의 호환**: TSPL 비트맵의 0=검정 가정, DIRECTION, 라벨 간격, ESC/POS 래스터 지원 여부는 기종마다 다를 수 있어 설정으로 고치도록 했습니다.
- **안드로이드 크롬에서의 동작**: 컴퓨터 크롬에서는 `file://`이 보안 컨텍스트임을 확인했지만(블루투스 등 보안 필요 기능 조건), 안드로이드 크롬에서 파일로 연 페이지가 블루투스·카메라 허용을 받는지는 확인하지 못했습니다. 안 되면 https 주소(예: GitLab Pages 등)로 올려 홈 화면에 추가하는 방법이 있으나 보안 검토가 필요합니다.
- 저가 태블릿의 사진 읽기 시간·메모리.
- 크롬을 닫았다 열면 프린터를 다시 골라야 할 수 있음(기억된 허용을 쓰는 방식은 크롬 버전에 따라 다름).

## 8. 후보 기종과 속도 (10.16 추가)
> 제 검색 도구는 해외 자료 중심이라 **국내 유통·원화 가격·재고는 확인하지 못했습니다.** 아래 후보는 다나와·쿠팡·네이버쇼핑·나라장터 종합쇼핑몰에서 모델명으로 다시 확인해야 합니다.

### 속도: 감열이 열전사보다 빠릅니다
열전사(리본)는 일반적으로 인쇄 속도가 더 느리고 리본 교체도 필요하며, 내구성이 필요한 라벨에 쓰입니다. 며칠 안에 쓰는 택배·주소 스티커는 감열이 가장 빠르고 간단합니다(출처 아래). 따라서 **속도 때문이라면 감열이 맞습니다.**
- 인쇄 시간: 100×45mm 스티커는 인쇄 속도 100~150mm/s 급이면 1초 안쪽입니다.
- 병목은 오히려 **블루투스 전송**: 100×45mm(203dpi)는 약 36KB. 앱 기본값(100바이트씩, 10ms 간격)은 쓰기 간격만으로 약 3.6초라서, 프린터가 받아 주면 「한 번에 보내는 크기」를 180~500바이트, 「간격」을 0~5ms로 올리세요(전송 약 1~2초 이내 예상). BLE 속도의 이론적 한계는 1Mbps(약 120KB/s) 안팎이고 실제는 기기에 따라 크게 다릅니다 — 실측 필요.

### 최소 시험 세트(권고)
태블릿 1대 + 프린터 2종(이동형 1·탁상형 1)을 먼저 사서(또는 대여해) 앱의 「블루투스 프린터 설정 → 프린터 연결 → 시험 인쇄」를 해 보고, 합격 기준을 확인합니다: ① 연결·재연결 ② 100×45 또는 80×50 스티커가 방향·크기 맞게 인쇄 ③ 한 장 전송+인쇄 시간 ④ 사진 읽기 시간 ⑤ 크롬을 껐다 켜도 다시 연결. 불합격이면 그 기종에 맞게 명령(ZPL·CPCL 등)을 추가해 맞춥니다.
