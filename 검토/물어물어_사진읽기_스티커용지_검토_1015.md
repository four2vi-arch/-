# 물어물어 v1.6 — 휴대폰 문자 사진으로 읽기 · 주소 스티커 용지 검토 (2026-10-15)

요청: ① 어르신이 휴대폰으로 받은 주소를 못 찾으실 때, 웹캠으로 화면을 찍어 글자로 읽고 프린터로 뽑아 드리는 기능 ② 기표지에 붙일 수 있는 국내 시판 감열 스티커 용지와 크기 검토.

## 1. 사진으로 읽기 — 만든 것

| 항목 | 내용 |
|---|---|
| 흐름(어르신 화면) | 「어디로 보내세요?」 화면의 **📷 휴대폰 문자를 사진으로 찍기** → 웹캠 미리보기(안내 선) → 사진 찍기 → 글자 읽기(2~3초) → 주소 후보(우편번호·주소·정확/비슷) → 맞는 주소를 누르면 기존 확인 화면 → 동·호 → 이름·전화(읽은 값 미리 채움, 확인만) → 접수 메모·**주소 스티커** |
| 흐름(직원 화면) | 「주소 찾기」 창 → **📷 사진으로 읽기** → 후보를 누르면 그 주소로 바로 찾기 |
| 글자 읽기 엔진 | Tesseract.js 5.1.1 + tesseract.js-core 5.1.1 + 한국어 학습자료(tessdata_best, 정수형) — 모두 Apache-2.0. **HTML 안에 내장**, 인터넷 불필요, 처음 쓸 때 1~2초 준비 |
| 파일 크기 | v1.5 12.07MB → v1.6 약 18.3MB(+6.2MB: 엔진 3.9MB, 한국어 자료 2.1MB, 기타) |
| 무결성 | 엔진 연결 코드·tesseract.min.js는 핵심 지문에 포함. 엔진 본체·작업자·한국어 자료(데이터 블록)는 **쓰기 직전 SHA-256을 빌드 때 박은 값과 대조**(다르면 사용 거부) |
| 개인정보 | 사진은 저장·전송하지 않음(읽은 직후 캔버스 0×0으로 지움). CSP `connect-src`가 이 PC·우체국 주소로 막혀 있어 밖으로 나갈 길도 없음. 워커용으로 `worker-src blob:`와 `'wasm-unsafe-eval'`만 추가(외부 스크립트 허용은 없음) |
| 검증 장치 | 읽은 글자를 그대로 믿지 않고, **우편번호 고시 DB로 다시 맞는 주소만 후보**로 냄(엔진이 맞춤법 검사기 역할). 읽은 이름·전화는 틀릴 수 있다는 안내와 함께 어르신이 확인 |

### 읽기 정확도를 올린 장치
- 두 번 읽음: 원본(문단 모드) + 명암 보정(흩어진 글자 모드). 어두운 화면(다크 모드)은 자동으로 뒤집어 읽음.
- 문자 화면은 줄바꿈이 낱말 한가운데서 나기도 해서(「충정로 2 / 34-1」) 줄을 이을 때 띄우기·붙이기·줄표 세 가지를 모두 DB에 물어 가장 잘 맞는 것을 씀.
- 시·군·구 이름이 두 글자까지 틀리게 읽혀도(정읍시→청릅시) 같은 주소의 시·도·**우리 동네(기본 지역)**로 좁혀질 때만 바로잡음(엔진 `fuzz:2`, 사진 읽기에서만 켬).
- 이름은 「받는 분/수취인/이름」 머리말이 있을 때만, 전화는 `010-…` 꼴이 맞을 때만 채움. 못 읽으면 비워 두어 어르신이 직접 적음.
- 주소를 못 찾으면 읽은 글자를 입력창에 채워 고쳐 쓰게 함.

### 시험(가상 문자 화면 사진: 가상 이름·전화, 공개 주소)
| 시험 | 결과 |
|---|---|
| 가까이 찍은 사진 6장(웹캠 720p로 줄여 읽음) | 첫 후보 주소 **6/6** 맞음, 이름·전화 **6/6** 맞음 |
| 일부러 어렵게 찍은 사진 6장(작고 흐림·기울어짐·잡음) | 첫 후보 **5/6**, 이름 5/6, 전화 3/6(틀린 값은 어르신 확인 화면에서 걸러짐) |
| 다크 모드(흑백 반전) 3장 | 3/3 맞음 |
| 어르신 화면 전 과정(사진→후보→확인→이름·전화→보내는 분→마침→스티커 인쇄) | 통과 |
| 직원 「주소 찾기」 사진 읽기, 카메라 거부·장치 없음 | 통과(안내만 하고 멈추지 않음, 단추 숨김) |
| 엔진 회귀 | v1.5와 2,000건 대조 **다름 0**, 모의 명단 1,000건 정확 1,000 |
| 기존 시험 | form_test 13/13, tail.js 정상, run.js 앞부분 정상 |

> 시험 사진은 컴퓨터로 그린 가상 문자 화면입니다. **실제 휴대폰·웹캠·조명 조건의 정확도는 현장에서 확인**해야 합니다(실제 숫자는 직접 돌려 본 값만 쓰세요).

## 2. 기표지에 붙일 감열 스티커

### 확인된 것(출처는 아래)
- **국내에서 감열(직접 열전사, 리본 없음) 접착 롤 라벨이 시판**됩니다. 쿠팡 판매 목록에서 100×150mm(택배 송장용, 500매), 100×80mm(600매), 80×40mm(1,000매), 80×50mm(500매), 70×50mm(500칸), 50×30mm(1,000~1,500매) 등이 확인됩니다. 가격 예: 100×150mm 500매 약 1만 원대(검색 시점 값, 구매 전 재확인).
- 인터넷우체국 간편사전접수의 **주소라벨 규격**은 2×6(1매 100×45mm)부터 3×9(1매 62.7×30.1mm)까지입니다(받는 분 라벨 2×6·2×7·2×8·3×7·3×8·3×9, 바코드 라벨은 3×7~3×9, 보내는 분 라벨 2×7). 출력 화면에 시험 출력 기능이 있습니다.
- 우편물 주소 안내: 받는 사람은 **오른쪽 아래**에 씁니다(인터넷우표 라벨도 수취인 주소 기재란에 붙이라고 안내).
- 접착 라벨 용지와 영수증용 연속 용지는 다른 종류입니다(접착 라벨은 뒷면 접착 + 바탕지, Zebra 문서의 용지 분류).

### 확인하지 못한 것(솔직히)
- **우체국 소포 기표지 「주소란」의 실제 가로·세로 규격**: 공개 자료에서 찾지 못했습니다. 그래서 크기를 **직접 재서 입력**하게 만들었습니다(아래 3절).
- 80mm 영수증 프린터로 접착 라벨을 쓸 수 있는지(연속 접착 롤 시판 여부·라벨 모드): 검색으로 확인되지 않았습니다. 라벨 프린터 모델별 호환(빅솔론 등 특정 기종)도 확인하지 못했습니다. **구매 전 프린터 사양서의 용지폭·라벨(갭/블랙마크) 지원 여부 확인 필요.**
- 인터넷우체국 라벨 출력 화면은 이 작업 환경에서 직접 열 수 없어 검색 결과 요약으로만 확인했습니다. 우체국 PC에서 한 번 직접 확인하세요.

### 권고
1. **방식**: 4인치(폭 100~108mm급) 데스크톱 **감열 라벨프린터** + 감열 접착 롤. 열전사(리본) 방식은 오래 보관·야외용이라, 소포에 붙여 며칠 안에 배달되는 주소 스티커는 **감열**로 충분합니다(감열은 열·햇빛에 변색하므로 장기 보관용은 아님).
2. **크기**: 기표지 주소란을 재서 다음 중 가장 큰 것을 고르세요. 앱은 모두 지원합니다.
   - 칸이 넉넉(가로 100mm 안팎): **100×45**(우체국 2×6과 같은 크기) 또는 100×50
   - 보통: 80×50 또는 70×50
   - 좁음: 60×40
   - 100×150은 택배 송장 한 장 크기 — 우체국 소포 기표지는 접수 때 전산으로 발급하므로 **대체 용도가 아니라** 주소 칸에 붙이는 보조용으로만 쓰세요.
3. **용지 폭 = 프린터 용지폭, 높이 = 라벨 높이**로 드라이버의 용지 크기를 앱 설정과 똑같이 맞추고, 감열 라벨 롤은 갭 센서 보정을 한 번 하세요.
4. 어르신 스티커에는 우편번호·받는 분·주소·전화·(보내는 분 작게)·접수번호가 들어갑니다. **바코드는 없습니다.** 우체국의 사전접수 바코드 라벨과 연동하는 것은 우정 전산 연계·보안 검토가 필요한 별도 과제로 남깁니다(인터넷우체국 간편사전접수는 자체 출력 라벨 붙여 접수하는 방식이 이미 있음 — 관련 할인 안내 글(postnews.kr)은 공식 자료가 아니라 최신 여부 확인 필요).

## 3. 현장에서 크기 맞추는 순서(약 5분)
1. 기표지 주소 쓰는 칸의 가로·세로를 자로 잽니다(여백 1~2mm 빼기).
2. 어르신 화면 오른쪽 아래 **직원**(2초 누르기) → 「종이로 뽑기 용지」 → **주소 스티커(라벨 프린터)** → 크기 입력(또는 목록에서 선택).
3. **스티커 시험 인쇄**를 눌러 한 장을 뽑아 기표지에 대 봅니다(테두리가 라벨 가장자리, 글자가 칸 안에 들어오는지). 맞지 않으면 숫자를 고쳐 다시.
4. 직원 화면의 「라벨 인쇄」에서도 **롤 스티커**를 고르면 주소록 전체를 한 장씩 뽑을 수 있습니다.

## 4. 이번에 함께 고친 것
- **직원 「라벨 인쇄」가 여러 쪽일 때 첫 쪽만 인쇄되던 문제**: 라벨 창이 모달(최상위 계층)이라 인쇄가 한 쪽만 나왔습니다(v1.5에서 A4 6칸 라벨 2장 분량을 인쇄 모양으로 재면 1쪽). 인쇄하는 동안만 일반 창으로 바꿔 여러 쪽이 모두 나오게 했고(시험: 2쪽), 인쇄 후 모달로 되돌립니다.
