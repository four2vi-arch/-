# 두 출품작 심사위원 모의 검토 결과와 개선 (2026-10-18)

요청: 두 개발작을 냉정한 심사자 입장에서 다시 보고 개선. 집중 질문 ① 사용자가 정말 편리한가 ② 생성 파일에 오류가 정말 하나도 없는가. 끝나면 GitLab에 올려 시험.

## 0. 방법
- 작품마다 「사용 편의」「생성 파일」 두 갈래, 모두 네 갈래로 나눠 각각 독립 검토(심사위원 역할, 저장소 읽기·실행만). 실제로 구동해 화면 갈무리·내려받은 파일을 기계 검사(openpyxl·LibreOffice·SheetJS, docx XML 파싱·렌더링).
- 결과를 다시 재현해 확인한 뒤 고치고, 고친 것마다 회귀 시험을 붙였다. 아래 「남김」은 이유와 함께 적었다.
- 결론부터: **두 작품 모두 「완전무결」이 아니었다.** 상(심각) 결함이 물어물어 7건(사용 5·파일 2), 돌다리 10건(사용 6·파일 4) 나왔고 전부 고쳤다. 중·하는 대부분 고쳤고, 남긴 것은 4절.
