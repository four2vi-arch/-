# 물어물어 × 라벨프린터(LABEL-9X00 계열) × 갤럭시 탭 S7 FE 검토(’26.10.23.)

사용자가 올린 프린터 매뉴얼(영문 스캔 16쪽, 「Thermal Label Printer Instruction Manual」)을 읽고, 물어물어 v1.10(출품본, 코드 그대로)의 태블릿 직접 인쇄와 맞춰 보았다. **검토만 했고 코드·판은 바꾸지 않았다**(10.23. 작업 원칙). 반영할 것은 진행대장 0절 「개선 대기 목록」에 올렸다. 같은 날 사용자가 만든 우리말 번역본(윈도우·안드로이드 사용 매뉴얼)을 원문과 쪽별로 대조했고(여러 검토자 대조 뒤 반박 검증), 뜻이 다른 곳은 없고 다듬을 곳 몇 줄만 있었다.

## 1. 매뉴얼 요점

| 항목 | 매뉴얼 내용 |
|---|---|
| 기종 | 4인치(폭 100mm급) 감열 라벨프린터. 드라이버 이름 「LABEL」, 맥에서는 「LABEL-9X00」으로 잡힘. 윈도 드라이버 LabelDriver.exe, 맥 드라이버 LabelPrinter 2.3.3 |
| 연결 단자 | USB·블루투스·네트워크(랜)·와이파이. **「구매 사양에 따라 단자가 다름」** → 이 기기 뒷면 확인 필요 |
| 블루투스 | 윈도에서 이름 「Bluetooth Printer」, **페어링 번호 1234**로 연결 = 클래식 블루투스(SPP) 방식. 맥은 블루투스 미지원 |
| 네트워크 | 랜 10/100, **TCP 9100 포트**, 와이파이 모듈(공유기 연결·자체 접속점 두 방식). 자체 시험 인쇄지에 블루투스 이름·주소와 IP가 찍힘 |
| 용지 | 롤(지름 100mm까지)·접이식(팬폴드) 둘 다. 맥 용지 목록에 100×100~100×250mm, 4×6인치 등. 사용자 정의 크기(예 50×30mm) 가능 |
| 명령 언어 | **매뉴얼에 없음**(TSPL·ESC/POS 등 어느 것을 받는지 적혀 있지 않음) |
| 용지 맞추기(보정) | 종이가 건너뛰거나 멈추지 않고 계속 나올 때: 종이를 넣고 전원을 켠 뒤 **FEED 단추를 5~6초** 눌러 불이 깜빡이고 삐 소리가 나면 뗀다. 프린터를 껐다 켜고 시험. 용지 규격이 바뀌면 보정값도 바뀜 |
| 이상 처리 ① | 보정한 뒤에도 종이가 있는데 오류: 종이를 빼고 전원을 끈 뒤 켜서 빨간 불이 깜빡이면 바로 FEED를 길게 → 다시 깜빡이고 삐 소리 → 떼고 2초 뒤 껐다 켜고 시험 |
| 이상 처리 ② | 보정한 뒤에도 종이가 없는데 오류가 안 남: 종이를 빼고 켜서 FEED 5~6초 → 빨간 불 깜빡이고 삐 두 번 → 떼고 껐다 켜고 시험 |
| 헤드 청소 | 글씨 흐림·세로 줄 빠짐·이송 소음·찌꺼기: 전원 끄고 헤드가 식은 뒤 무수 에탄올을 짠 부드러운 면천으로 닦고, 다 마르면 덮개를 닫음. 손·쇠붙이로 헤드를 건드리지 말고 휘발유·아세톤 금지 |

## 2. 물어물어 v1.10과 맞춰 보기

물어물어의 태블릿 직접 인쇄(`src/blep.js`)는 스티커를 그림으로 그려 흑백 점으로 바꾼 뒤 TSPL 또는 ESC/POS 명령으로 보낸다. 길은 셋이다: 「기기 인쇄 창」(크롬 인쇄), 「USB 선(OTG)」(WebUSB), 「블루투스(BLE)」(Web Bluetooth).

| 이 프린터의 연결 | 물어물어로 바로 인쇄 | 판단 |
|---|---|---|
| USB | 된다(가능성 높음) | 윈도에서 「USB001」 프린터 포트로 잡히는 걸 보면 USB 프린터 종류 장치다. 안드로이드 크롬 WebUSB는 프린터 종류 인터페이스를 열 수 있다(물어물어가 이것을 가장 먼저 고르게 되어 있음). **S7 FE에서 주된 길로 권함.** 실기 확인 전 |
| 블루투스 | 안 될 가능성이 큼 | 매뉴얼의 연결은 페어링 번호(1234) 방식 = 클래식 블루투스(SPP). 웹 페이지(Web Bluetooth)는 저전력 블루투스(BLE)만 쓸 수 있다. 모듈이 BLE를 같이 내보내면 되지만 매뉴얼로는 알 수 없음. 확인법은 3절 ⑤ |
| 네트워크·와이파이(9100) | 안 된다 | 웹 페이지는 9100 포트로 직접 보낼 수 없다. 제조사 앱이 안드로이드 「인쇄 서비스」를 깔아 주는 경우에만 「기기 인쇄 창」으로 될 수 있음(확인 필요) |
| 제조사 앱(QR) | 물어물어와 별개 | 안드로이드 QR은 구글 플레이 「Print Label」(com.print.label)로 이어짐. 앱 소개상 블루투스·USB 연결, PDF·라벨 인쇄. 물어물어 스티커를 그 앱으로 넘기는 기능은 없음. 앱이 USB를 지원한다는 점은 이 프린터가 안드로이드 USB로 받는다는 좋은 신호 |

용지: 물어물어 스티커 크기 선택지는 100×45(기본, 인터넷우체국 라벨 2×6 규격)·100×50·80×50·70×50·60×40·100×150(택배 송장 크기)이다. 이 프린터는 폭 100mm급이라 모두 들어간다. 100×150은 기표지 주소란에는 크고 소포 상자에 맞는 크기다. TSPL은 인쇄할 때마다 크기·간격(기본 2mm)을 같이 보내므로, 라벨 롤의 간격이 다르면 설정 창 「라벨 간격」을 맞추고 프린터 쪽은 1절 보정을 한 번 한다.

## 3. S7 FE에서 확인할 것(사용자 실기, 순서대로)

1. **프린터 뒷면 단자**(USB만인지, 블루투스·랜·와이파이가 있는지)와 **가진 라벨 롤 크기**(가로×세로, 간격).
2. **자체 시험 인쇄지**: 이 매뉴얼에는 방법이 없다. 흔한 방법은 전원을 끈 채 FEED를 누르고 켠 뒤 삐 소리에 떼는 것(기종마다 다름). 찍히면 명령 언어(TSPL 등)·블루투스 이름이 나오는지 본다.
3. **물어물어 여는 방식**: 「내 파일」에서 눌러 열기와 크롬 주소창 열기 가운데 어느 것으로 열었는지 적어 둔다. 프린터 연결 설정에서 USB를 골랐는데 「이 브라우저에서는 USB 인쇄를 쓸 수 없어요」가 나오면 크롬 탓이 아니라 **여는 방식이 「안전한 연결」로 인정되지 않은 것**일 수 있다(헤드리스 크로미움의 file:// 열기는 안전한 연결로 잡힘. 안드로이드 「내 파일」 열기(content://)는 확인 못 함). 이때 설정이 저장되는지도 같이 본다.
4. **USB 연결**: USB-C(OTG)↔프린터 USB 선, 또는 하루 종일 켜 둘 거면 **충전 겸용(PD) USB-C 허브**(S7 FE는 단자가 하나라 프린터를 꽂으면 충전을 못 함). 프린터 연결 설정 → 인쇄 방식 「USB 선(OTG)」 → 「프린터 연결」 → 안드로이드 허용 → 「시험 인쇄」. 명령은 TSPL 먼저, 안 나오면 ESC/POS. 테두리·10mm 눈금이 라벨 가장자리와 맞는지, 거꾸로면 회전 180도, 검은 바탕이면 색 반전.
   - 제조사 앱을 깔았다면 USB를 꽂을 때 뜨는 「이 앱으로 열기」에서 **「항상」을 고르지 않는다**(앱이 프린터를 잡으면 크롬이 못 연다).
5. **블루투스(BLE) 확인**: 인쇄 방식 「블루투스(BLE)」 → 「프린터 연결」 → 크롬 선택 창에 프린터 이름이 뜨면 BLE가 있는 것, 안 뜨면 SPP 전용이라 USB로 간다. 안드로이드 12 이상은 크롬의 「근처 기기」 권한, 11 이하는 「위치」를 켜야 검색된다.
6. **용지 이상**: 건너뛰거나 계속 나오면 1절 보정(FEED 5~6초).
7. **하루 운영**: 화면 자동 꺼짐 시간, 삼성 「앱 고정」(어르신이 크롬 밖으로 나가지 않게), 충전.
8. **화면 크기**: 가로·세로 각각에서 화면이 잘리거나 단추가 가려지지 않는지(아래 4절은 기기 크기를 추정한 자동 확인).

## 4. 화면 자동 확인(헤드리스, v1.10 그대로)

S7 FE 크롬과 비슷하다고 본 크기(가로 1280×712: 주소창을 뺀 높이를 추정, 세로 800×1192, 터치·모바일 모드)로 어르신 화면 첫 화면·입력·결과·프린터 연결 설정 창을 찍어 보았다. 가로 넘침 없음, 페이지 오류 없음, 설정 창이 한 화면에 다 들어감. 가로 화면은 내용이 가운데 980px 칸에 있어 아래쪽이 비어 보인다(문제는 아님). 실제 화면 배율(CSS 크기)은 기기에서 확인해야 한다.

## 5. 반영 후보(파일 요청 때 한 번에, 위에서부터 중요)

| 순서 | 내용 | 까닭 |
|---|---|---|
| 가 | 프린터 연결 설정 창에 **「이 기기 상태」 한 줄**: 열린 방식(file·content·https), 안전한 연결 여부, 블루투스·USB를 쓸 수 있는지 | 지금은 여는 방식 문제여도 「안드로이드 크롬이 필요해요」로만 나와 원인을 못 찾는다 |
| 나 | 설정 창 안내 글 보강: 용지 보정(FEED 5~6초)·라벨 크기를 바꾸면 보정, 페어링 번호로 잇는 블루투스 프린터(SPP)는 안 됨 → USB로, 네트워크 프린터는 바로 인쇄 안 됨, 안드로이드 12 이상 「근처 기기」 권한, 제조사 앱 「항상」 금지 | 이 매뉴얼의 프린터가 그대로 부딪힐 일 |
| 다 | 시험 인쇄·인쇄 실패 문구에 「종이가 건너뛰거나 계속 나오면 FEED 5~6초 보정」 | 현장에서 가장 흔한 라벨 문제 |
| 라 | 어르신 화면 직원 메뉴에 **「전체 화면」** 단추, 어르신 화면이 켜져 있는 동안 **화면 꺼짐 막기** | 안드로이드 크롬에는 PC의 `--kiosk` 실행이 없어 주소창이 남고 화면이 꺼진다 |
| 마 | (실기 결과에 따라) 인쇄 진하기·위치 미세 조정(가로·세로 mm) | 시험 인쇄가 흐리거나 어긋날 때만 |
| 바 | (실기 결과에 따라) 100×150 라벨을 쓰면 소포 상자용 큰 배치 | 기표지 주소란용(100×45)과 쓰임이 다름 |
| 사 | README·구동안내서 「확인한 장비」에 기종·연결 방식·결과 | 실기 뒤. 지금 문서의 「실제 프린터·태블릿 확인 전」 문구는 그대로 맞음 |

가~라는 프린터가 없어도 고칠 수 있고 가짜 프린터 자동 시험(블루투스 29·USB 25항목)으로 확인할 수 있다. 마·바·사는 3절 실기 결과를 받은 뒤 정한다. 물어물어 출품본은 v1.10(SHA-256 6447728b…c5f5e4)을 그대로 두기로 한 계획(진행대장 2절 11.3.~11.6. 줄)이 있으므로, 가~라를 넣어 재빌드할지는 반영 때 사용자와 정한다.
